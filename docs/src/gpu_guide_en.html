Before you start

Five minutes of reading that save you time later.

What this guide covers, and what it does not

It covers NVIDIA Control Panel, the driver settings that NVIDIA itself provides, plus the Windows and monitor settings that go with them. It never edits a game file or hooks into a game, so anti-cheat systems do not treat it as cheating.

About the example driver, 582.78

News sites report that 582.78 is a GeForce Security Update Driver for GeForce GTX 750 to GTX 10 series cards (Maxwell, Pascal and Volta), published at the end of September 2026. NVIDIA stopped Game Ready drivers for these cards in October 2025 and has announced security updates until October 2028. In plain words:

  • The driver brings no new game optimizations. Nothing in this guide depends on a newer driver.
  • If your games run well, you do not need to update the driver every month. Update when a security update appears.
  • The Control Panel pages look the same as before. To see your version, click System Information at the bottom left of NVIDIA Control Panel: the Display tab shows "Driver version".

These facts come from news coverage. NVIDIA's own driver page and release notes are the authority: check nvidia.com if the exact wording matters to you.

Honest expectations

Most options change FPS by 0 to 3%. The ones that really change how a game feels are power management mode, low latency mode, V-Sync / G-SYNC / frame cap and the refresh rate. In-game settings and your CPU matter more than all driver options together.

Three safety habits

  • Take a screenshot of each page before you change it (Windows key + Shift + S).
  • Restore Defaults at the top right of a page puts that page back to the NVIDIA defaults.
  • Nothing is saved until you press Apply at the bottom right of the page.

Path: 3D Settings, Adjust image settings with preview.

  1. Select Use the advanced 3D image settings. The slider underneath turns grey, which is what you want.
  2. Press Apply at the bottom right.

Press Apply, then check

Press Apply at the bottom right. Your screenshot may show other values than the "Set to" column. Follow the column. "Every setting explained" near the end of this guide has the long version of each row.

Step 3. Configure Surround, PhysX

Path: 3D Settings, Configure Surround, PhysX.

  1. Open the Processor drop-down (marker 1) and choose your GeForce card instead of Auto-select. Auto normally picks the card anyway; naming it only removes the chance of physics work landing on the CPU.
  2. Leave "Span displays with Surround" unticked. Surround is for three-screen setups.
  3. Press Apply.

Step 4. Change resolution

Path: Display, Change resolution. This page has no screenshot here because it lists your own screens.

  1. Select the gaming screen at the top.
  2. Resolution: the one marked "native" (2560 x 1440 for the screen in the screenshots).
  3. Refresh rate: the highest value (144 Hz). A 144 Hz screen left at 60 Hz is the most common reason for "my FPS feels low".
  4. Under Choose the color settings select Use NVIDIA color settings and set Output color format: RGB, Output color depth: 8 bpc, Output dynamic range: Full. Most games and Windows use 8 bits, and a higher depth gives no benefit with them. Full range keeps blacks black (Limited is for TVs).
  5. Press Apply. Windows shows "Keep changes?": press Yes.

If the screen goes black

Do nothing for 15 seconds. Windows returns to the old mode by itself if you do not confirm.

Step 5. Adjust desktop size and position

Path: Display, Adjust desktop size and position.

  1. Scaling mode (marker 1). When the game runs at your screen's native resolution, the mode makes no difference. When it runs lower, Aspect ratio keeps the picture the right shape. Full-screen stretches it. No scaling leaves black borders.
  2. Perform scaling on (marker 2). GPU is the safe default. Display lets the monitor do the scaling, which is a little faster on some screens and worse looking on others. Try it only if you play below native resolution.
  3. Override the scaling mode set by games and programs (marker 3). Leave it unticked, so games can use their own scaling. Tick it only if one game shows a stretched picture.

Rule of thumb

Play at native resolution and this page needs no change at all.

Step 6. Set up G-SYNC

Path: Display, Set up G-SYNC.

  1. Tick Enable G-SYNC, G-SYNC Compatible (marker 1). This lets the screen follow your FPS, so you get no tearing without the delay of V-Sync.
  2. Choose Enable for full screen mode (marker 2). It covers fullscreen and the fullscreen-style windows of most games. "Windowed and full screen" also works for windowed games.
  3. Select your gaming screen (marker 3), then tick Enable settings for the selected display model (section 3 of the page).
  4. Read the line under it. "Selected Display is not validated as G-SYNC Compatible" means NVIDIA has not tested that model. It often works, but NVIDIA does not promise a perfect result. If you see flicker or black flashes, untick the box again.
  5. Marker 4: "To enable this monitor set it as primary display". If you see this line, open the Set up multiple displays link, or Windows Settings, System, Display, select the gaming screen and tick Make this my main display. Press Apply on both pages.

Use DisplayPort

With a GTX 10 series card, G-SYNC Compatible needs a DisplayPort connection (DisplayPort 1.2a or newer). HDMI variable refresh rate needs a newer card than Pascal, according to hardware sites. If your screen is on HDMI, move the cable to DisplayPort.

Step 7. Program Settings: different values for one game

Global Settings apply to everything. Program Settings apply to one game and win over Global. Use it for the one or two games that need something else (for example Low Latency Mode Ultra for a GPU-heavy game).

  1. 3D Settings, Manage 3D settings, tab Program Settings.
  2. Press Add and pick the game's .exe (or choose it from the list).
  3. Change only the rows you need. Everything else stays Use global setting.
  4. Press Apply. To undo, set the row back to "Use global setting", or press Restore.

Why 3 FPS below the refresh rate?

Blur Busters, who tested G-SYNC in detail, recommend a frame cap a few FPS below the refresh rate (about 3 to 5%) together with V-Sync on in the Control Panel. The game then always stays inside the G-SYNC range, so V-Sync never adds its usual delay. It is community-tested guidance, not an NVIDIA rule. If the game has its own FPS limit, use that one first: it adds the least delay.

Low Latency Mode: On or Ultra?

SituationChoose
The graphics card is the limit (GPU usage 95 to 99%): heavy, good-looking gamesUltra for that game (Program Settings). It cuts the render queue.
The CPU is the limit (GPU usage clearly below 95%): esports, very high FPSOn (Global). Ultra gives little and can cost a few FPS.
The game has NVIDIA ReflexTurn Reflex On in the game and leave the driver at On. Reflex does the same job better.
DirectX 12 or Vulkan gameThe driver setting does nothing there. Use Reflex if offered.
G-SYNC with V-Sync (style B) and UltraUltra also keeps FPS under the refresh rate by itself. Fine, but then you do not need the cap.

How to see which limit you have: open Task Manager, Performance, GPU while you play. It needs no overlay and nothing hooks into the game. GPU at 95% or more means the card is the limit. Lower means the CPU or the game is.

NVIDIA Control Panel and the NVIDIA App

The NVIDIA App is a separate program from NVIDIA Control Panel. It replaces GeForce Experience and holds the per-game settings and the DLSS overrides. NVIDIA announced in 2025 that it was moving some of the most requested 3D settings into the app; the Control Panel is still there and is what this guide uses. Features that need an RTX card are not available on a GTX 10 series card, and a security-only driver such as 582.78 adds no features.

A row you do not know? Match settings by name, not by position: rows can move between driver versions. If a row of this guide is missing, skip it. If a new row appears, click it and read the Description box at the bottom of the page (visible in the screenshots). When in doubt leave the default.

Windows and monitor checks

The driver is only half of the picture. Check these five places too.

1

Windows refresh rate

Settings, System, Display, Advanced display, choose the gaming screen, Choose a refresh rate: the highest value. (Tool menu H, "PC health", checks this for you.)

2

Variable refresh rate in windowed games

Settings, System, Display, Graphics, Change default graphics settings. Turn on Optimizations for windowed games (Windows 11). It lets G-SYNC work in borderless and windowed games that use DirectX 10 or 11.

3

Hardware-accelerated GPU scheduling

Same page, Hardware-accelerated GPU scheduling. The effect is small and differs per PC. Turn it on, restart, play a game you know. If it stutters more, turn it off again. (This optimizer's tweak 08 sets it.)

4

Game Mode and power mode

Settings, Gaming, Game Mode: On. Settings, System, Power, Power mode: Best performance (plugged in).

5

The monitor's own menu (OSD)

Turn on Adaptive-Sync (some brands call it FreeSync). Leave Overdrive / response time on the middle value: the highest setting can add a ghost-like halo. Check that the screen is not in an eco or low-power picture mode.

Two screens

  • The screen you game on must be the main display (see step 7 of the quick setup).
  • A second screen with another refresh rate can make a game stutter. If you see that, close videos and animations on the second screen while you play.
  • Use a DisplayPort cable for the gaming screen. Use the cable that came with the monitor if you are not sure.

What gives more FPS than any driver option

  • In-game settings. Shadows, volumetric effects, view distance and render scale cost far more than any driver option.
  • CPU limit. A CPU with many cores but a low clock per core limits many games. Lowering the resolution does not help then.
  • Cooling and power. A hot card or CPU lowers its clocks. Clean dust and check airflow.
  • RAM at its rated speed. Turn on XMP / EXPO in the BIOS. Tool menu H shows if the RAM runs below its rating.

The driver: update, clean install, roll back

How to change the driver without losing your settings, or your PC.

Update the driver

  1. Go to nvidia.com, Drivers, and choose GeForce, series GeForce 10 Series, product GeForce GTX 1070, your Windows version. Download the newest driver the page lists.
  2. Run the installer. Choose NVIDIA Graphics Driver (and the HD audio driver if you use HDMI or DisplayPort audio).
  3. Choose Custom (Advanced) only if you want a clean installation (next section). Otherwise Express is fine.
  4. Restart the PC when the installer asks.

Easy Setup and drivers

Windows 11 Optimizer never installs a graphics driver for you. Easy Setup only opens the maker's download page when the graphics card has just the basic Windows driver.

Clean installation

A clean installation removes the saved settings of the old driver and starts from the NVIDIA defaults. Use it when you have stutter, crashes or odd colours that started after a driver change.

  1. Take screenshots of your Control Panel pages first. A clean installation also resets them.
  2. In the installer choose Custom (Advanced), press Next, tick Perform a clean installation, press Next.
  3. Restart, then set the Control Panel again with this guide.

A third-party tool called DDU removes even more leftovers and is run in Safe Mode. It is a last resort for stubborn problems and is not part of this project.

Roll back a driver that caused trouble

  1. Right-click Start, Device Manager, Display adapters, double-click your GeForce card.
  2. Tab Driver, button Roll Back Driver, follow the steps, restart.
  3. If the button is grey: Windows has no older driver stored. Install the previous version from nvidia.com instead, or use the restore point Before_Driver_Install from this optimizer's driver tool.

Clear the shader cache

If one game stutters after a driver change, clear the cache once: Start, type Disk Cleanup, choose drive C:, tick DirectX Shader Cache, OK. The first run of each game afterwards is slower while the cache fills again.

Glossary

The words of this guide in plain language.

WordMeaning
G-SYNC / Adaptive-Sync / FreeSyncVariable refresh rate: the screen changes its refresh rate to match your FPS, so frames are not torn or delayed. "G-SYNC Compatible" is NVIDIA's name for using a FreeSync or Adaptive-Sync monitor.
V-SyncMakes the card wait for the screen's refresh before showing a frame. Stops tearing, adds delay when the FPS is below the refresh rate.
TearingA horizontal split in the picture where two frames meet.
Frame capA limit on FPS, set in the game or the driver.
Input lag / latencyThe time between your mouse click and the result on screen.
NVIDIA ReflexA game option that shortens the render queue. Better than the driver's Low Latency Mode in games that offer it.
Render queueFrames that the CPU has prepared and the GPU has not drawn yet. A long queue means more delay.
GPU-bound / CPU-boundWhich part limits your FPS. GPU usage at 95% or more means GPU-bound.

Sources and limits

Where the advice comes from, and how far to trust it.

  • Setting names, options and defaults come from NVIDIA Control Panel itself (the help text under each page, visible in the screenshots) and its well-known behavior.
  • G-SYNC and frame cap: the advice to enable G-SYNC and V-Sync in the Control Panel, switch V-Sync off in the game and cap a few FPS below the refresh rate is community-tested guidance from Blur Busters, "G-SYNC 101" (blurbusters.com/gsync/gsync101-input-lag-tests-and-settings). It is not an NVIDIA rule.
  • Low Latency Mode: works in DirectX 9 to 11 games and not in DirectX 12 or Vulkan, according to several hardware sites and forums. NVIDIA Reflex is described on NVIDIA's own Reflex page.
  • Newer cards and the NVIDIA App: DLSS overrides, Smooth Motion and the move of some 3D settings into the NVIDIA App come from NVIDIA's own news pages (nvidia.com/geforce/news, "NVIDIA App Update Adds DLSS 4 Overrides..." and the global DLSS overrides and RTX 40 Smooth Motion announcement) and Tom's Hardware. Resizable BAR and HDMI details come from general hardware knowledge: check your own card's specification.
  • Driver 582.78: reported by TweakTown, Guru3D and other news sites as a security-only driver for Maxwell, Pascal and Volta (GTX 750 to GTX 10 series). Searched on 20 October 2026. NVIDIA's own release notes were not available to this guide, so check nvidia.com for the exact notes.
  • DisplayPort and HDMI: G-SYNC Compatible over DisplayPort 1.2a or newer, and no HDMI variable refresh on Pascal cards, come from hardware sites (Wikipedia, Igor's Lab). Check your monitor's manual.
  • Clean installation: the steps follow common vendor documentation (for example Dell's support article about NVIDIA clean installation).

Limits

Results differ per game and per PC. Treat the recommended values as a good starting point, not a promise. Change one thing at a time and compare the same scene before and after. This guide is not NVIDIA documentation.
