NVIDIA Driver Settings for Gaming

What every setting does, a recommended value, and when to choose something else

Read this first

  • This guide is only about NVIDIA Control Panel, the driver settings that NVIDIA itself provides. It does not touch any game file, so it is not game modification and anti-cheat systems do not treat it as cheating. Do not combine it with tools that edit game files or hook into the game.
  • Written around a GeForce GTX 1070 (Pascal), and valid for most GTX 10, 16, RTX 20, 30, 40 and 50 cards. Names and defaults can differ slightly between driver versions. If an option is missing on your card, skip it.
  • Honest expectation: most options below change FPS by 0 to 3%. The ones that really matter are Power management mode, Low Latency Mode, V-Sync / G-SYNC / frame cap and the refresh rate. In-game settings and your CPU matter more than all of them.

Before you start (2 minutes)

  • Open it: right-click the desktop > NVIDIA Control Panel (Windows 11: Show more options first). If it is missing, install NVIDIA Control Panel from the Microsoft Store.
  • Take screenshots of the pages you change, so you can go back. The Restore button on a page puts that page back to the NVIDIA defaults.
  • Apply with the Apply button at the bottom right of each page. Nothing is saved until you press it.

Global Settings or Program Settings?

Manage 3D settings has two tabs. Global Settings applies to every game and program. Program Settings applies to one program only and overrides Global. A good method: set Global to the safe values in this guide, then use Program Settings for the one or two games that need something different (for example Low Latency Mode = Ultra on a GPU-heavy game).

Step 1: Adjust image settings with preview

1Use the advanced 3D image settings
  • What it is: the page has a slider ("Use my preference emphasizing: Performance / Quality") and an "advanced" choice.
  • Recommended: Use the advanced 3D image settings. The slider is a preset that silently changes image-quality options and overrides what you set in Manage 3D settings. With the advanced choice, every value you set yourself is used as it is. The FPS difference between the two is small (about 1 to 2%), but only the advanced choice lets you know exactly what is set.

Configure Surround, PhysX

Set the PhysX processor to your GeForce card instead of Auto-select. Auto normally chooses the card anyway; naming it only removes the chance of the work landing on the CPU.

Choose your style: two ready profiles

V-Sync and Max Frame Rate set the feel more than any other option

AMaximum FPS, lowest lag (esports: Valorant, CS2, Overwatch and similar)
  • Vertical sync = Off, Max Frame Rate = Off (or a cap above your refresh rate).
  • Low Latency Mode = On; use Ultra only if the game keeps the GPU at 95% or more.
  • Price: tearing (the picture shows a horizontal split) on some frames. In return you get the lowest delay.
BSmooth picture, no tearing, low lag (single-player and most games)
  • Set up G-SYNC: on. Vertical sync = On in NVIDIA Control Panel, and Off inside the game.
  • Max Frame Rate = your refresh rate minus 3 (for example 144 Hz screen: 141). Staying just under the refresh rate keeps G-SYNC active, so V-Sync does not add its usual delay.
  • Low Latency Mode = On (Ultra automatically keeps FPS under the refresh rate when G-SYNC and V-Sync are on).
  • Price: FPS cannot go above the cap. Use exclusive fullscreen if the game offers it.

Low Latency Mode: On or Ultra?

SituationChoose
GPU is the limit (usage 95 to 99%): heavy, good-looking gamesUltra for that game (Program Settings). It cuts the render queue and the lag is lower.
CPU is the limit (GPU usage clearly below 95%): esports, very high FPSOn (Global). Ultra gives little here and can cost a few FPS or add stutter.
The game has NVIDIA ReflexTurn Reflex On in the game and leave the driver at On. Reflex does the same job better.
DirectX 12 or Vulkan gameThe driver setting does nothing; the game manages its own queue. Use Reflex if offered.

How to see which limit you have: open Task Manager > Performance > GPU while playing. This needs no overlay and nothing hooks into the game. If GPU stays at 95% or more, the graphics card is the limit; if it is lower while FPS is capped by something else, the CPU (or the game) is.

Set up G-SYNC

  • Tick Enable G-SYNC, G-SYNC Compatible. Choose Enable for full screen mode (best for games). "Windowed and full screen" also works for borderless games.
  • If your screen shows "not validated", tick Enable settings for the selected display model. If you see flicker or black screens, untick it again: not every FreeSync/VRR screen is fully compatible.
  • Also check that Variable refresh rate is on in Windows Settings > System > Display > Graphics.
  • With two screens at different refresh rates, a game on one screen can stutter because of the other one. If you see that, close videos and animations on the second screen while you play.

Change resolution

  • Resolution = your screen's native one. Refresh rate = the highest it offers (a 144 Hz screen left at 60 Hz is a very common cause of "my FPS feels low").
  • Output dynamic range = Full if the option appears (HDMI sometimes defaults to Limited, which makes the picture look washed out). PC monitors normally use Full.

Keeping it safe, and getting more FPS

What is safe for anti-cheat, what to avoid, and what else matters

Safe (driver and Windows settings)

  • Everything in the tables above, the Windows graphics settings, in-game settings changed through the game's own menus, and launch options that the game's maker documents.
  • Updating the graphics driver from NVIDIA (choose Custom and tick Perform a clean installation only if you have had problems).

Avoid (can get an account banned)

  • Editing or replacing game files (.exe, .dll, asset or pak files), injecting DLLs, memory editors, and "FPS unlocker" programs for online games.
  • Config tweaks that remove textures, shadows or effects so enemies are easier to see. Many games treat that as an unfair advantage.
  • Overlays and tools that hook into the game. Some are allowed by some games and banned by others; read the game's own rules first.
  • Hidden driver profile editors: not covered here, they are unsupported by NVIDIA.

What gives more FPS than any driver option

LeverWhy
Screen refresh rateMake sure it is the highest the screen supports (Windows Settings > Display > Advanced display, and the NVIDIA page above). The PC Health tool (menu H) checks this.
In-game settingsShadows, volumetric effects, view distance and render scale cost far more than any driver option. Lower those first.
CPU limitA CPU with many cores but a low clock per core limits many games. Lowering the resolution does not help then; lowering view distance, crowd and effects does.
Cooling and powerA hot card or CPU lowers its clocks. Clean dust and check airflow.
RAM at its rated speedTurn on XMP / EXPO in the BIOS. The PC Health tool (menu H) shows if the RAM runs below its rating.
Windows settingsHardware-accelerated GPU scheduling (this optimizer's tweak 08) and Game Mode. Their effect is small and differs per PC: change one thing at a time and compare.

If something goes wrong

  • Stutter, flicker, crashes after a change: press Restore on that page, or on Manage 3D settings press Restore, then change settings one at a time.
  • One game misbehaves: select it in Program Settings and set the setting you changed back to Use global setting.
  • To compare fairly, measure with the same scene and the same in-game settings before and after, and change one value at a time.

Sources

Setting names, options and defaults come from NVIDIA Control Panel itself (the help text in each page) and common documentation of its behavior. The G-SYNC and frame-cap advice (cap about 3 FPS under the refresh rate) is community-tested guidance from Blur Busters (blurbusters.com, "G-SYNC 101"), not an NVIDIA rule. NVIDIA Reflex is described on NVIDIA's own Reflex page. Results differ per game and PC: treat the recommended values as a good starting point, not a promise.
