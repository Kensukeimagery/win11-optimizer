คู่มือ

ตั้งค่าไดรเวอร์ NVIDIA สำหรับเล่นเกม

แต่ละค่าคืออะไร ค่าที่แนะนำ และเมื่อไหร่ควรเลือกอย่างอื่น

อ่านก่อน

  • คู่มือนี้เกี่ยวกับ NVIDIA Control Panel เท่านั้น คือการตั้งค่าไดรเวอร์ที่ NVIDIA จัดไว้ให้เอง ไม่แตะไฟล์เกมใดๆ จึงไม่ใช่การแก้ไขเกม และระบบกันโกงไม่ถือว่าเป็นการโกง อย่าใช้ร่วมกับเครื่องมือที่แก้ไฟล์เกมหรือแทรกเข้าไปในเกม
  • เขียนโดยยึด GeForce GTX 1070 (Pascal) เป็นหลัก และใช้ได้กับการ์ด GTX 10, 16, RTX 20, 30, 40 และ 50 ส่วนใหญ่ ชื่อและค่าเริ่มต้นอาจต่างเล็กน้อยตามเวอร์ชันไดรเวอร์ ถ้าการ์ดของคุณไม่มีตัวเลือกไหน ให้ข้ามไป
  • ความคาดหวังที่เป็นจริง: ตัวเลือกส่วนใหญ่ด้านล่างเปลี่ยน FPS ราว 0-3% ที่มีผลจริงคือ Power management mode, Low Latency Mode, V-Sync / G-SYNC / การจำกัดเฟรม และรีเฟรชเรต การตั้งค่าในเกมและตัวซีพียูมีผลมากกว่าทั้งหมดนี้

ก่อนเริ่ม (2 นาที)

  • เปิดโปรแกรม: คลิกขวาที่เดสก์ท็อป > NVIDIA Control Panel (Windows 11: กด Show more options ก่อน) ถ้าไม่มี ให้ติดตั้ง NVIDIA Control Panel จาก Microsoft Store
  • ถ่ายภาพหน้าจอของหน้าที่จะเปลี่ยนไว้ เผื่อย้อนกลับ ปุ่ม Restore ในแต่ละหน้าจะคืนค่าหน้านั้นเป็นค่าเริ่มต้นของ NVIDIA
  • กดปุ่ม Apply มุมล่างขวาของแต่ละหน้า ยังไม่กดคือยังไม่บันทึก

Global Settings หรือ Program Settings?

หน้า Manage 3D settings มี 2 แท็บ Global Settings ใช้กับทุกเกมและโปรแกรม Program Settings ใช้กับโปรแกรมเดียวและทับค่า Global วิธีที่ดีคือตั้ง Global เป็นค่าปลอดภัยตามคู่มือนี้ แล้วใช้ Program Settings กับเกมหนึ่งสองเกมที่ต้องการค่าต่างออกไป (เช่น Low Latency Mode = Ultra ในเกมที่การ์ดจอทำงานหนัก)

  • แนะนำ: Use the advanced 3D image settings แถบเลื่อนเป็นพรีเซ็ตที่เปลี่ยนค่าคุณภาพภาพให้โดยไม่บอก และทับสิ่งที่คุณตั้งใน Manage 3D settings ถ้าเลือก advanced ทุกค่าที่คุณตั้งเองจะถูกใช้ตามนั้น FPS ต่างกันไม่มาก (ราว 1-2%) แต่มีแค่ advanced ที่ทำให้คุณรู้ชัดว่าตั้งอะไรไว้

Configure Surround, PhysX

ตั้ง PhysX processor เป็นการ์ด GeForce ของคุณแทน Auto-select ปกติ Auto ก็เลือกการ์ดอยู่แล้ว การระบุชื่อแค่ตัดโอกาสที่งานจะไปตกที่ซีพียู

เลือกสไตล์: 2 โปรไฟล์สำเร็จรูป

V-Sync กับ Max Frame Rate กำหนดความรู้สึกมากกว่าตัวเลือกอื่น

AFPS สูงสุด หน่วงต่ำสุด (เกมแข่ง: Valorant, CS2, Overwatch ฯลฯ)
  • Vertical sync = Off, Max Frame Rate = Off (หรือจำกัดไว้สูงกว่ารีเฟรชเรต)
  • Low Latency Mode = On ใช้ Ultra เฉพาะเมื่อเกมทำให้การ์ดจอแตะ 95% ขึ้นไปตลอด
  • ราคาที่จ่าย: ภาพฉีก (มีรอยแบ่งแนวนอน) บางเฟรม แลกกับความหน่วงต่ำสุด
Bภาพลื่น ไม่ฉีก หน่วงต่ำ (เกมเล่นคนเดียวและเกมส่วนใหญ่)
  • Set up G-SYNC: เปิด Vertical sync = On ใน NVIDIA Control Panel และ Off ในเกม
  • Max Frame Rate = รีเฟรชเรตลบ 3 (เช่นจอ 144 Hz ตั้ง 141) อยู่ต่ำกว่ารีเฟรชเรตเล็กน้อยทำให้ G-SYNC ยังทำงาน V-Sync จึงไม่เพิ่มความหน่วงตามปกติ
  • Low Latency Mode = On (Ultra จะคุม FPS ให้ต่ำกว่ารีเฟรชเรตเองเมื่อเปิด G-SYNC กับ V-Sync)
  • ราคาที่จ่าย: FPS สูงกว่าเพดานที่ตั้งไม่ได้ ใช้ exclusive fullscreen ถ้าเกมมี

Low Latency Mode: On หรือ Ultra?

สถานการณ์เลือก
การ์ดจอเป็นตัวจำกัด (ใช้งาน 95-99%): เกมหนักภาพสวยUltra เฉพาะเกมนั้น (Program Settings) ตัดคิวเรนเดอร์ ความหน่วงต่ำลง
ซีพียูเป็นตัวจำกัด (การ์ดจอใช้งานต่ำกว่า 95% ชัดเจน): เกมแข่ง FPS สูงมากOn (Global) Ultra ได้ผลน้อยตรงนี้ และอาจเสีย FPS เล็กน้อยหรือกระตุกขึ้น
เกมมี NVIDIA Reflexเปิด Reflex On ในเกม และปล่อยไดรเวอร์ไว้ที่ On Reflex ทำหน้าที่เดียวกันได้ดีกว่า
เกม DirectX 12 หรือ Vulkanค่าในไดรเวอร์ไม่มีผล เกมจัดการคิวเอง ใช้ Reflex ถ้ามี

วิธีดูว่าอะไรเป็นตัวจำกัด: เปิด Task Manager > Performance > GPU ขณะเล่น ไม่ต้องใช้ overlay และไม่มีอะไรแทรกเข้าไปในเกม ถ้า GPU ค้างที่ 95% ขึ้นไป การ์ดจอคือตัวจำกัด ถ้าต่ำกว่านั้นขณะที่ FPS ถูกจำกัดด้วยสิ่งอื่น ตัวจำกัดคือซีพียู (หรือตัวเกม)

Set up G-SYNC

  • ติ๊ก Enable G-SYNC, G-SYNC Compatible เลือก Enable for full screen mode (เหมาะกับเกมที่สุด) "Windowed and full screen" ใช้กับเกม borderless ได้ด้วย
  • ถ้าจอขึ้น "not validated" ให้ติ๊ก Enable settings for the selected display model ถ้าเจอจอกะพริบหรือดับ ให้เอาติ๊กออก เพราะจอ FreeSync/VRR บางรุ่นเข้ากันได้ไม่สมบูรณ์
  • เช็กด้วยว่า Variable refresh rate เปิดอยู่ใน Windows Settings > System > Display > Graphics
  • ถ้ามี 2 จอที่รีเฟรชเรตต่างกัน เกมบนจอหนึ่งอาจกระตุกเพราะอีกจอ ถ้าเจอ ให้ปิดวิดีโอและแอนิเมชันบนจอที่สองตอนเล่น

Change resolution

  • Resolution = ความละเอียดจริงของจอ Refresh rate = ค่าสูงสุดที่จอมี (จอ 144 Hz ที่ค้างอยู่ที่ 60 Hz เป็นสาเหตุที่พบบ่อยมากของอาการ "FPS รู้สึกต่ำ")
  • Output dynamic range = Full ถ้ามีตัวเลือกนี้ (HDMI บางทีตั้งเป็น Limited ทำให้ภาพซีด) จอคอมพิวเตอร์ปกติใช้ Full

ความปลอดภัย และวิธีเพิ่ม FPS เพิ่มเติม

อะไรปลอดภัยกับระบบกันโกง อะไรควรเลี่ยง และอะไรอีกที่มีผล

ปลอดภัย (ตั้งค่าไดรเวอร์และ Windows)

  • ทุกอย่างในตารางข้างบน การตั้งค่ากราฟิกของ Windows การตั้งค่าในเกมผ่านเมนูของเกมเอง และ launch options ที่ผู้ทำเกมระบุไว้
  • การอัปเดตไดรเวอร์การ์ดจอจาก NVIDIA (เลือก Custom และติ๊ก Perform a clean installation เฉพาะเมื่อเคยมีปัญหา)

ควรเลี่ยง (อาจทำให้บัญชีโดนแบน)

  • แก้หรือแทนที่ไฟล์เกม (.exe, .dll, ไฟล์ asset หรือ pak) การฉีด DLL ตัวแก้หน่วยความจำ และโปรแกรม "FPS unlocker" สำหรับเกมออนไลน์
  • การปรับ config ที่ลบเท็กซ์เจอร์ เงา หรือเอฟเฟกต์ เพื่อให้เห็นศัตรูง่ายขึ้น หลายเกมถือว่าเป็นการได้เปรียบอย่างไม่ยุติธรรม
  • overlay และเครื่องมือที่แทรกเข้าไปในเกม บางเกมอนุญาต บางเกมแบน อ่านกติกาของเกมนั้นก่อน
  • โปรแกรมแก้โปรไฟล์ไดรเวอร์แบบซ่อน: ไม่ครอบคลุมในคู่มือนี้ NVIDIA ไม่รับรอง

อะไรให้ FPS มากกว่าตัวเลือกไดรเวอร์

รีเฟรชเรตของจอให้เป็นค่าสูงสุดที่จอรองรับ (Windows Settings > Display > Advanced display และหน้า NVIDIA ข้างบน) เครื่องมือ PC Health (เมนู H) ตรวจให้
ค่าในเกมเงา volumetric effects ระยะมองเห็น และ render scale กินมากกว่าตัวเลือกไดรเวอร์ใดๆ มาก ลดตัวเหล่านี้ก่อน
ขีดจำกัดของซีพียูซีพียูหลายคอร์แต่ความเร็วต่อคอร์ต่ำ เป็นตัวจำกัดเกมจำนวนมาก การลดความละเอียดไม่ช่วยในกรณีนี้ ลดระยะมองเห็น จำนวนฝูงชน และเอฟเฟกต์จึงจะช่วย
ความร้อนและไฟการ์ดหรือซีพียูร้อนจะลดความเร็วเอง ทำความสะอาดฝุ่นและเช็กการระบายอากาศ
แรมวิ่งตามความเร็วสเปกเปิด XMP / EXPO ใน BIOS เครื่องมือ PC Health (เมนู H) แสดงว่าแรมวิ่งต่ำกว่าสเปกหรือไม่
ค่าของ WindowsHardware-accelerated GPU scheduling (tweak 08 ของโปรแกรมนี้) และ Game Mode ผลเล็กน้อยและต่างกันรายเครื่อง เปลี่ยนทีละอย่างแล้วเทียบ

ถ้ามีอะไรผิดปกติ

  • กระตุก ภาพกะพริบ หรือแครชหลังเปลี่ยน: กด Restore ในหน้านั้น หรือในหน้า Manage 3D settings กด Restore แล้วเปลี่ยนค่าทีละอย่าง
  • เกมเดียวมีปัญหา: เลือกเกมนั้นใน Program Settings แล้วตั้งค่าที่เปลี่ยนกลับเป็น Use global setting
  • การเปรียบเทียบที่แฟร์: วัดฉากเดิมและค่าในเกมเดิมก่อนและหลัง และเปลี่ยนทีละค่า

แหล่งอ้างอิง

ชื่อค่า ตัวเลือก และค่าเริ่มต้น มาจาก NVIDIA Control Panel เอง (ข้อความช่วยเหลือในแต่ละหน้า) และเอกสารทั่วไปเรื่องการทำงานของมัน คำแนะนำเรื่อง G-SYNC และการจำกัดเฟรม (ต่ำกว่ารีเฟรชเรตราว 3 FPS) เป็นแนวทางที่ชุมชนทดสอบจาก Blur Busters (blurbusters.com, "G-SYNC 101") ไม่ใช่กฎของ NVIDIA NVIDIA Reflex อธิบายไว้ในหน้า Reflex ของ NVIDIA ผลต่างกันตามเกมและเครื่อง ให้ถือค่าที่แนะนำเป็นจุดเริ่มต้นที่ดี ไม่ใช่คำสัญญา
