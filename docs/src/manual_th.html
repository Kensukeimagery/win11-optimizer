ก่อนเริ่มใช้

อ่านสองนาที เพื่อความปลอดภัยของเครื่อง

อ่านก่อนใช้

  • ใช้ด้วยความเสี่ยงของตัวเอง สคริปต์แก้ registry และ power settings ใช้กับเครื่องที่เป็นของคุณเท่านั้น และเก็บจุดคืนค่าที่สคริปต์สร้างไว้เสมอ
  • ออกแบบสำหรับ เดสก์ท็อป Windows 11 ที่เล่นเกม ถ้าใช้กับโน้ตบุ๊ก ความร้อนจะสูงขึ้นและแบตเตอรี่หมดเร็วขึ้น (CPU ขั้นต่ำ 100%, ปิด power throttling)
  • ผลที่ได้เล็กน้อยและขึ้นกับสถานการณ์ ไดรเวอร์การ์ดจอ การตั้งค่าในเกม XMP/EXPO และการระบายความร้อนสำคัญกว่ามาก ดูหมายเหตุตามจริงของแต่ละข้อด้านล่าง
  • แอนตี้ไวรัสบางตัวอาจเตือนไฟล์ .bat ที่แก้ registry ทุกไฟล์เป็นข้อความธรรมดา เปิดอ่านก่อนรันได้

สิ่งที่ต้องมี

  • คอมพิวเตอร์ที่ใช้ Windows 11 (build 22000 ขึ้นไป) และบัญชีที่เป็น ผู้ดูแลระบบ (administrator) ถ้าเป็น Windows รุ่นเก่า โปรแกรมจะเตือนก่อน
  • เวลาราว 30 นาที ส่วนใหญ่คือรอสร้างจุดกู้คืนและรอ Windows Update
  • เปิด System Protection (System Restore) ของไดรฟ์ C: ไว้ เพื่อให้สร้างจุดกู้คืนได้ โปรแกรมจะพยายามเปิดให้เอง ถ้าไม่สำเร็จ ดูวิธีเปิดเองในหัวข้อแก้ปัญหา
  • มีอินเทอร์เน็ตจะดีที่สุด ถ้าไม่มี ขั้นที่ต้องใช้อินเทอร์เน็ตจะถูกข้าม ส่วนที่เหลือยังทำงานได้
  • ทุกโฟลเดอร์ที่ดาวน์โหลดมาต้องอยู่ด้วยกัน ห้ามย้ายไฟล์ .bat ออกจากโฟลเดอร์

โปรแกรมทำอะไร และไม่ทำอะไร

สิ่งที่ทำสิ่งที่ไม่ทำ
สร้างจุดกู้คืนก่อนเปลี่ยนอะไรทุกครั้งลบไฟล์หรือเกมของคุณ
ปรับค่า registry และ power ที่มีเอกสารรองรับ แต่ละค่ามีไฟล์ยกเลิกของตัวเองแก้ไฟล์เกม ฉีดโค้ดเข้าเกม หรือเพิ่ม overlay
ติดตั้งไดรเวอร์ที่แนะนำจาก Windows Update ไม่แตะไดรเวอร์การ์ดจอของผู้ผลิตหรือเฟิร์มแวร์ติดตั้งโปรแกรมของบริษัทอื่นหรือโปรแกรม "อัปเดตไดรเวอร์"
แสดงสเปกเครื่อง สุขภาพเครื่อง และอาการแครชด้วยภาษาที่เข้าใจง่ายรับรองตัวเลข FPS: ผลที่ได้เล็กน้อยและขึ้นกับเกม
อัปเดตตัวเองเมื่อคุณตอบตกลงเท่านั้น พร้อมตรวจ SHA-256ส่งข้อมูลของคุณไปที่ใด: ติดต่อ github.com เพื่อเช็กอัปเดต และ Microsoft เพื่อไดรเวอร์เท่านั้น

ตอบหนึ่งคำถาม

  • หน้าต่างสีดำเป็นภาษาอังกฤษทั้งหมด คู่มือเล่มนี้อธิบายเป็นภาษาไทยในทุกขั้น และมีตารางแปลข้อความที่จะเจอ
  • "Do you mainly play games on this PC? Y/N" (คุณใช้เครื่องนี้เล่นเกมเป็นหลักไหม) กด Enter สำหรับไม่ใช่ หรือ Y สำหรับใช่ ถ้าตอบใช่ จะเพิ่มค่าเมาส์ คีย์บอร์ด timer, CPU boost, ปรับเกมแบบหน้าต่างให้ไวขึ้น, Game Mode และการ์ดเน็ต และมีคำถามที่สอง: Maximum ใส่ทุกค่าเสริมในครั้งเดียว (รวม 18 ถึง 25: ไดรเวอร์เฉพาะที่ลงเอง, โปรแกรมเริ่มต้นเปิดทันที, เมนูไว, ปรับเกมแบบหน้าต่าง, การ์ดเน็ต, Game Mode, End task, ปิดแอปพื้นหลัง) ส่วนการปิด Memory Integrity (ค่า 13) ต้องพิมพ์ YES แยกต่างหาก เพราะลดการป้องกัน
  • ไม่แน่ใจ? กด Enter ได้ จะเพิ่มค่าเสริมทีหลังก็ได้ (เมนูหลัก ปุ่ม 2)
  • อ่านแผน แล้วกด Y เพื่อเริ่ม

Check if a newer version of this tool exists (you decide). 2. Make a safety point (System Restore) so you can always go back. 3. Remember how the PC is now, to show before and after. 4. ปล่อยให้ทำงานครบสิบขั้น

โปรแกรมแสดง "ขั้นที่ 3 จาก 10" ไปเรื่อยๆ ส่วนใหญ่คุณไม่ต้องทำอะไร

ขั้นสิ่งที่เห็นสิ่งที่คุณทำ
1 ตรวจอัปเดต"Check for a newer version of this tool now?" (ตรวจหาเวอร์ชันใหม่ตอนนี้ไหม)กด Enter ถ้ามีเวอร์ชันใหม่ จะถามว่าจะอัปเดตไหม
2 จุดกู้คืน"Making the safety point... 1 to 5 minutes" (กำลังสร้างจุดกู้คืน)รอ อย่าปิดหน้าต่าง
3 จดสถานะ"Saved how the PC is now" (จดสถานะเครื่องแล้ว)ไม่ต้องทำอะไร
4 อินเทอร์เน็ต"The internet works." หรือ "No internet" (ไม่มีอินเทอร์เน็ต)ถ้าไม่มี: เสียบสาย LAN หรือเชื่อม Wi-Fi แล้วกด R กด S เพื่อข้ามขั้นที่ต้องใช้เน็ต ค่าต่างๆ ยังตั้งได้
5 Windows Updateหน้า Windows Update เปิดขึ้นกด Check for updates ติดตั้งให้หมด แล้วกลับมาที่หน้าต่างสีดำและกด Enter กด S เพื่อข้ามขั้นนี้
6 ไดรเวอร์"Drivers installed: 0. ..." (ติดตั้งไดรเวอร์แล้ว)ไม่ต้องทำอะไร ถ้าการ์ดจอมีแค่ไดรเวอร์พื้นฐาน จะเสนอเปิดหน้าดาวน์โหลดของผู้ผลิต: กด Y เพื่อเปิด
7 รีสตาร์ท"Windows needs a restart..." (Windows ต้องรีสตาร์ท เฉพาะเมื่อต้อง)กด R หลังรีสตาร์ท เปิด 0_Easy_Setup อีกครั้งและกด Enter ที่ "Continue where it stopped?" (ทำต่อจากที่ค้างไว้ไหม)
8 ตั้งค่า"Applying the settings..." (กำลังตั้งค่า) ราว 1 นาทีไม่ต้องทำอะไร
9 DNS"Test the internet speed and pick a faster DNS?" (ทดสอบเน็ตและเลือก DNS ที่เร็วกว่าไหม)กด Enter (ไม่ทำ) ผลต่างเล็กน้อย
10 สรุปหน้าจอ SUMMARY (สรุปผล) หลัง 30 วินาทีถึง 2 นาทีอ่านสรุป (ขั้นถัดไป)

ตัวอย่างเท่านั้น ตัวเลขของคุณจะต่างออกไป "L = I will restart later, R = restart now" คือ L = รีสตาร์ททีหลัง, R = รีสตาร์ทเลย

  • Speed settings in place (การตั้งค่าความเร็วที่อยู่ครบ) เทียบเครื่องก่อนและหลัง ตัวเลขที่สองควรเท่ากับยอดรวม

แอปบน Windows

ชอบใช้เมาส์? เปิด Win11 Optimizer.exe แล้วคลิกได้เลย

โปรแกรม Win11 Optimizer.exe อยู่ในโฟลเดอร์หลัก ข้างไฟล์ .bat ทั้งสาม ไม่ต้องติดตั้ง Windows จะขอสิทธิ์ผู้ดูแลระบบหนึ่งครั้งตอนเปิด หน้าตาแสดงสิ่งเดียวกับเมนูข้อความ แต่เป็นปุ่มและสวิตช์ และแค่สั่งสคริปต์ของเครื่องมือนี้ ใช้แอปหรือไฟล์ .bat ก็ได้ ผลเหมือนกัน

หน้าทำอะไรที่นั่น
หน้าหลักกด เริ่ม Easy Setup เลือกว่าคุณใช้เครื่องแบบไหน แล้วมันจะทำงานในหน้าต่างของมันเอง ด้านล่างเห็นว่ามีกี่ค่าที่อยู่ครบ และปุ่ม แก้ให้ ถ้า Windows เปลี่ยนบางค่ากลับ
การปรับแต่งสวิตช์หนึ่งตัวต่อหนึ่งข้อ (01 ถึง 16 และ 18 ถึง 25) พร้อมสถานะ: เปิด ปิด หรือ Windows เปลี่ยนกลับ จะเสนอสร้างจุดกู้คืนก่อนเปลี่ยนครั้งแรก เปิดทุกข้อที่แนะนำ ใช้ข้อ 01 ถึง 08
เครื่องมือสเปกเครื่อง สุขภาพเครื่อง รายงานระบบ และชุดไฟล์สนับสนุน ทำงานในหน้าต่างนี้และแสดงผลให้ ส่วนทดสอบเครือข่าย ไดรเวอร์ ล้างไฟล์เก่า และตรวจสถานะ เปิดหน้าต่างของมันเอง เพราะมีคำถามให้ตอบ
ย้อนกลับปิดสวิตช์ทีละข้อในหน้าการปรับแต่ง ย้อนทั้งเครื่องด้วย System Restore หรือเปิดโฟลเดอร์ Backup และ Logs

#ขั้นตอนทำอะไรทำไมตอนนี้
1เวอร์ชันใหม่ถามว่าจะตรวจไหม ถ้ามีเวอร์ชันใหม่ อัปเดตเครื่องมือนี้ได้ใช้ตัวที่แก้ไขล่าสุดตั้งแต่แรก
2จุดกู้คืนสร้าง System Restore ชื่อ Before_PC_Optimizerทุกอย่างหลังจากนี้ย้อนกลับได้
3จดสถานะตอนนี้นับการตั้งค่าความเร็วที่อยู่ครบ กับอุปกรณ์ที่ไม่มีไดรเวอร์ และเก็บสเปคเครื่องเพื่อแสดงก่อนและหลัง
4อินเทอร์เน็ตตรวจการเชื่อมต่อ ถ้าไม่มีจะอธิบายวิธีแก้ (ไดรเวอร์เครือข่ายจากผู้ผลิตเมนบอร์ดหรือโน้ตบุ๊ก คัดลอกด้วยแฟลชไดรฟ์)การอัปเดตและไดรเวอร์ต้องใช้
5Windows Updateเปิด Windows Update คุณกด Check for updates ติดตั้งทั้งหมด และรีสตาร์ทถ้าขออัปเดตอาจเปลี่ยนการตั้งค่า จึงทำก่อน
6ไดรเวอร์ติดตั้งไดรเวอร์ที่แนะนำจาก Windows Update (เครือข่าย เสียง บลูทูธ chipset) ไม่สำรองไดรเวอร์ทั้งชุด เพราะมีจุดกู้คืนแล้ว ถ้าการ์ดจอมีแต่ไดรเวอร์พื้นฐาน จะเปิดหน้าดาวน์โหลดของผู้ผลิตระบบเดียวกับ 7_Driver_Check ที่ปลอดภัย
7รีสตาร์ทเสนอเฉพาะเมื่อ Windows ต้องการ แล้วรันไฟล์เดิมเพื่อทำต่อไดรเวอร์ใหม่ต้องใช้
8ตั้งค่าความเร็วแบบปลอดภัยเมนู 1, 3 และ 4 คำตอบเรื่องเกมเพิ่มเมาส์ คีย์บอร์ด timer, CPU boost, ปรับเกมแบบหน้าต่าง, Game Mode และการตั้งค่าการ์ดเน็ต ส่วน Maximum เพิ่ม Fullscreen Exclusive, Ndu, ไดรเวอร์เฉพาะที่ลงเอง, โปรแกรมเริ่มต้นเปิดทันที, เมนูไว, End task และปิดแอปพื้นหลัง ด้วย โน้ตบุ๊กข้ามสิ่งที่ทำให้ร้อนหรือกินแบตทำท้ายสุด อัปเดตและไดรเวอร์จะได้ไม่ย้อนค่า
9DNS ที่เร็วกว่าทดสอบเครือข่ายและเลือก DNS เป็นตัวเลือก ค่าเริ่มต้นคือไม่ผลน้อย ไม่บังคับ
10ตรวจผลและสรุปการตั้งค่าที่ครบก่อน/หลัง อุปกรณ์ที่ไม่มีไดรเวอร์ เรื่องที่ควรดู วิธีย้อนกลับ และเตือนให้รีสตาร์ทเห็นผลในหน้าเดียว

ไม่รวมโดยตั้งใจ

การล้างไดรเวอร์, การล้างไฟล์ขยะลึก, Network Reset, การเปลี่ยน DNS โดยไม่ถาม, การลบแอป Windows และการติดตั้งโปรแกรม เป็นของเฉพาะกรณี อยู่ในเมนูหลักและ repair-tools Memory Integrity (13) จะถูกใช้เฉพาะเมื่อคุณเลือก Maximum และพิมพ์ YES

ใช้วิธีที่เล็กที่สุดที่แก้ปัญหาได้

Aย้อนทีละข้อ - เมนู 7
  • เช่น เมาส์รู้สึกแปลกหลังใช้ไฟล์ 10 ให้พิมพ์ 7 แล้ว 10
  • คืนเป็นค่าเริ่มต้นของ Windows จากโฟลเดอร์ reg_undo T = เอาค่า network ออก, P = รีเซ็ต Power Plan ทั้งหมด
  • สคริปต์จำไว้ว่าคุณย้อนข้อนี้ ตัวตรวจสถานะจะแสดงเป็น SKIPPED และไม่ถามให้ลงซ้ำ
Bคืนค่าเดิมแบบตรงตัว - โฟลเดอร์ Backup
  • ทุกครั้งที่รัน สคริปต์ export คีย์เดิมไว้ใน Backup\วันเวลา
  • ดับเบิลคลิกไฟล์ในนั้นเพื่อคืนค่าที่เครื่องคุณเคยมีจริง (ละเอียดกว่าค่าเริ่มต้นของ Windows)
Cย้อนทั้งเครื่อง - 2_Revert_Everything

  • เครื่องรีสตาร์ทเอง และโปรแกรมที่ติดตั้งหลังจุดนั้นจะหายด้วย ใช้เมื่อปัญหาหนักเท่านั้น

2_Revert_Everything ใช้จุดกู้คืนไหน

จุดล่าสุดที่ชื่อ Before_PC_Optimizer ถ้ารัน Easy Setup หรือกด 5 ซ้ำ จะได้จุดใหม่ชื่อเดียวกัน จุดเก่าจึงไม่ใช่เป้าหมายอีก

ดูแลให้ใช้งานได้ต่อเนื่อง

ตรวจสถานะ (เมนู C) และอัปเดต (เมนู U) More Tools\3_Check_Status ทำงานเหมือนเมนู C

ตรวจสอบสถานะ

1รัน 3_Check_Status แบบ administrator
  • สคริปต์ไล่ตรวจทุกรายการ แสดงสถานะทีละบรรทัดพร้อมค่าปัจจุบันเทียบกับค่าที่ควรเป็น
2ตอบคำถามแก้ไข
  • ข้อแนะนำ: Y = ลงซ้ำทุกข้อที่หาย, S = เลือกทีละข้อ, N = ไม่แก้
  • ข้อเสริมถามทีละข้อเสมอ ส่วนข้อ 13 ต้องพิมพ์ YES
  • ก่อนลงซ้ำจะสำรองค่าเดิมไว้ใน Backup\วันเวลา_check
3ตรวจซ้ำอัตโนมัติ
  • หลังแก้เสร็จสคริปต์ตรวจข้อที่แก้อีกรอบเพื่อยืนยัน บันทึกผลเป็น CheckReport_วันเวลา.txt แล้วรีสตาร์ท 1 ครั้ง
สถานะหมายความว่าสิ่งที่สคริปต์ทำ
OKค่ายังอยู่ครบตามที่สคริปต์ตั้งไว้ไม่ต้องทำอะไร
CHANGEDมีบางค่าถูกเปลี่ยน เช่นหลังอัปเดต Windowsลงซ้ำได้
MISSINGไม่พบค่าของข้อนี้เลยลงซ้ำได้
NOT CHOSENข้อเสริม (09-13, 15, 16, 18-25) ที่ยังไม่เคยตอบถาม: Y ลง, N ยังไม่ลง, X ไม่ต้องถามอีก
SKIPPEDข้อที่คุณเลือกข้ามหรือย้อนกลับไว้ไม่ถาม ไม่แก้
UNKNOWNอ่านค่าไม่ได้ หรือเครื่องไม่มีตัวเลือกนี้ให้ข้อมูลเท่านั้น

การอัปเดต

Uการอัปเดต: เมนู U หรือ 6_Check_For_Updates.bat
  • ตรวจหาเวอร์ชันใหม่บน GitHub แสดงว่ามีอะไรใหม่ และติดตั้งเฉพาะเมื่อคุณกด U N = ยังไม่ทำ, S = ข้ามเวอร์ชันนี้, L = เปิดหน้า Release
  • ออกแบบให้ปลอดภัย: ไฟล์ที่ดาวน์โหลดถูกตรวจกับค่า SHA-256 ที่ประกาศพร้อม Release เวอร์ชันเดิมถูกย้ายไป Backup\update_เวอร์ชันเดิม_เวลา และถ้าขั้นตอนใดล้มเหลวจะใส่กลับให้ โฟลเดอร์ Backup, log และรายงานของคุณไม่ถูกแตะเลย
  • ครั้งแรกที่เปิดเมนูจะถามหนึ่งครั้งว่าจะตรวจอัตโนมัติตอนเริ่มไหม (เชื่อมต่อ github.com และไม่ส่งข้อมูลเกี่ยวกับคุณ) กด A เพื่อเปิดหรือปิด ไม่มีอะไรถูกติดตั้งโดยที่คุณไม่เลือก
  • การอัปเดตจาก v4.5 หรือเก่ากว่าต้องดาวน์โหลด ZIP เองหนึ่งครั้ง ตั้งแต่ v4.6 เป็นต้นไป โปรแกรมอัปเดตตัวเองได้

แก้ปัญหา

หาอาการของคุณในคอลัมน์ซ้าย

อาการหมายความว่าวิธีแก้
หน้าต่างสีน้ำเงิน "Windows protected your PC"SmartScreen ยังไม่รู้จักไฟล์ เป็นเรื่องปกติของไฟล์ .bat ใหม่กด More info แล้ว Run anyway ครั้งต่อไป ให้ปลดล็อก ZIP ก่อนแตกไฟล์ (เริ่มใช้งานด่วน ขั้น 2)
แอนตี้ไวรัสบล็อกหรือลบไฟล์แอนตี้ไวรัสบางตัวเตือนไฟล์ .bat ที่แก้ registryตรวจว่าโหลดจากหน้าโปรเจกต์ และเปิดอ่านไฟล์ได้ ห้ามปิดแอนตี้ไวรัส ถ้ายังบล็อก อย่าใช้ไฟล์นั้น
"Please right-click this file and choose Run as administrator"คุณเปิดด้วยการดับเบิลคลิกธรรมดาคลิกขวาที่ไฟล์แล้วเลือก Run as administrator ยังไม่มีอะไรถูกเปลี่ยน
หน้าต่างค้าง แถบชื่อขึ้นต้นด้วย "Select"คุณคลิกในหน้าต่างสีดำ ทำให้หยุดชั่วคราวกด Esc แล้วจะทำต่อ
"The argument ... does not exist" หรือ "not recognized" หลังพิมพ์คำสั่งพิมพ์ผิด หรืออยู่ผิดโฟลเดอร์เปิดโฟลเดอร์ที่แตกไฟล์ พิมพ์ cmd ในช่อง address แล้วกด Enter และคัดลอกคำสั่งมาวางแทนการพิมพ์
"The safety point could not be made" (สร้างจุดกู้คืนไม่สำเร็จ)System Protection ของไดรฟ์ C: ปิดอยู่เมนู Start พิมพ์ Create a restore point เลือก C: กด Configure เลือก Turn on system protection กด OK แล้วรัน Easy Setup ใหม่
"No internet" (ไม่มีอินเทอร์เน็ต) ในขั้น 4ไม่มีการเชื่อมต่อ หรือเครื่องไม่มีไดรเวอร์เครือข่ายเสียบสาย LAN หรือต่อ Wi-Fi แล้วกด R ถ้าไม่มีไดรเวอร์เครือข่าย ให้โหลดจากเว็บผู้ผลิตเมนบอร์ดหรือโน้ตบุ๊กด้วยเครื่องอื่น แล้วคัดลอกมาด้วยแฟลชไดรฟ์ หรือกด S เพื่อข้ามขั้นที่ใช้เน็ต
หน้า Windows Update ไม่เปิดบางเครื่องบล็อกทางลัดเปิด Settings แล้ว Windows Update เอง หรือกด S เพื่อข้ามขั้นนี้
"An earlier Easy Setup was started... Continue?" (เคยเริ่ม Easy Setup ไว้แล้ว ทำต่อไหม)คุณปิดกลางทางหรือเครื่องรีสตาร์ทกด Y (หรือ Enter) เพื่อทำต่อจากที่ค้าง กด N เพื่อเริ่มใหม่
หลัง Windows อัปเดต ค่าต่างๆ กลับเป็นปกติWindows รีเซ็ตบางค่า เกิดขึ้นได้กด C ในเมนูหลักแล้วยืนยัน
เครื่องร้อนขึ้นหรือพัดลมดังขึ้นUltimate Performance และ CPU boost ทำให้ซีพียูทำงานเร็วตลอดย้อนค่า 16 (เมนู 7 แล้วกด 16) หรือเลือก Balanced ใน Power Options ถ้าเป็นโน้ตบุ๊ก ให้ข้ามค่าเสริม
เมาส์รู้สึกแปลกค่า 10 ปิด pointer accelerationเมนู 7 แล้วกด 10
เกมแจ้งเรื่องความปลอดภัยหรือ anti-cheatกฎ anti-cheat เป็นของผู้ทำเกม เครื่องมือนี้เปลี่ยนเฉพาะการตั้งค่า Windowsเปิด S (สเปกเครื่อง) เพื่อดู Secure Boot และ TPM ที่บางเกมต้องใช้ ถ้าปิด Memory Integrity (13) ไว้ ให้ย้อน: เมนู 7 แล้วกด 13
มีอะไรพังหลังติดตั้งไดรเวอร์ไดรเวอร์ใหม่ไม่เหมาะกับอุปกรณ์Device Manager เลือกอุปกรณ์ แล้ว Roll Back Driver หรือใช้ System Restore เลือก Before_Driver_Install
อยากให้ใครช่วยดูชุดไฟล์สนับสนุนรวบรวมสิ่งที่เขาต้องใช้กด B อ่านไฟล์ใน Logs แล้วแนบใน issue ที่ github.com/Kensukeimagery/win11-optimizer

Restore point (จุดกู้คืน)ภาพบันทึกการตั้งค่า Windows ที่ System Restore ย้อนกลับไปได้ ไม่แตะเอกสารของคุณ
Registryฐานข้อมูลที่ Windows เก็บการตั้งค่า แต่ละค่าในเครื่องมือนี้เปลี่ยนไม่กี่รายการในนั้น
ไฟล์ .regไฟล์ข้อความเล็กๆ ที่ตั้งค่า registry เปิดอ่านด้วย Notepad ได้ ทุกค่ามีไฟล์นี้และมีไฟล์ยกเลิก
Driver (ไดรเวอร์)ซอฟต์แวร์ที่ให้ Windows สื่อสารกับอุปกรณ์ เช่น การ์ดจอหรือชิปเสียง
Windows Updateบริการของ Microsoft สำหรับแพตช์และไดรเวอร์จำนวนมาก
SmartScreenระบบตรวจของ Windows ที่เตือนเมื่อพบไฟล์ที่ไม่รู้จัก
SHA-256 checksumลายนิ้วมือของไฟล์ ตัวอัปเดตเทียบกับค่าที่ประกาศไว้ เพื่อให้แน่ใจว่าไฟล์ที่โหลดครบถ้วน
BIOS / UEFIหน้าตั้งค่าเฟิร์มแวร์ที่เข้าได้ตอนเปิดเครื่อง (มักกด Delete หรือ F2)
XMP / EXPOโปรไฟล์หน่วยความจำใน BIOS ที่ทำให้ RAM ทำงานที่ความเร็วตามสเปก
Secure Boot, TPMฟีเจอร์ความปลอดภัยที่ Windows 11 และบางเกม เช่น Valorant ต้องใช้ หน้าสเปกเครื่องแสดงว่าเปิดอยู่หรือไม่
FPS และ 1% lowsเฟรมต่อวินาที ส่วน 1% lows คือช่วงที่ช้าที่สุด ซึ่งกำหนดว่าเกมลื่นแค่ไหน
Ping, jitter, packet lossความหน่วงไปยังเซิร์ฟเวอร์ ความแกว่งของความหน่วง และสัดส่วนแพ็กเก็ตที่ไม่ถึง jitter คืออาการที่รู้สึกเป็นภาพกระตุกกลับ
DNSบริการแปลงชื่อเว็บเป็นที่อยู่ ใช้ครั้งเดียวตอนเชื่อมต่อ และไม่เปลี่ยน ping ในเกม
Refresh rate (Hz)จำนวนครั้งที่จอรีเฟรชต่อวินาที จอ 144 Hz ที่ตั้งไว้ 60 Hz จะรู้สึกเหมือนอินพุตหน่วง
Memory Integrityฟีเจอร์ความปลอดภัยของ Windows (HVCI) ปิดแล้วอาจเพิ่ม FPS ในบางเครื่อง แต่ป้องกันเครื่องน้อยลง
Power planชุดกฎเรื่องพลังงาน Ultimate Performance ทำให้ซีพียูเร็วตลอดและไม่ปิดคอร์
Core parkingWindows ปิดคอร์ซีพียูที่ว่างเพื่อประหยัดไฟ การตั้งค่า power ที่นี่ปิดฟีเจอร์นี้
SSD, HDDไดรฟ์โซลิดสเตตและฮาร์ดดิสก์ Windows และเกมเร็วกว่าเมื่ออยู่บน SSD

คำถามที่พบบ่อย

ปลอดภัยไหม?

สร้างจุดกู้คืนก่อน เปลี่ยนเฉพาะการตั้งค่า Windows ที่มีเอกสารรองรับ และทุกค่ามีทางยกเลิก เปิดอ่านทุกไฟล์ก่อนรันได้ ใช้กับเครื่องของคุณเองเท่านั้น และเก็บจุดกู้คืนไว้

FPS จะเพิ่มไหม?

เพิ่มเล็กน้อย และเฉพาะบางเกม ค่าที่ปรับมีผลเล็ก การตั้งค่าไดรเวอร์การ์ดจอ การตั้งค่าในเกม XMP/EXPO และการระบายความร้อนสำคัญกว่ามาก ระวังโปรแกรมที่สัญญาว่าจะเพิ่มได้มาก

จะโดนแบนในเกมไหม?

ไม่แก้ไฟล์เกม ไม่ฉีดโค้ด และไม่เพิ่ม overlay เปลี่ยนเฉพาะการตั้งค่า Windows กฎ anti-cheat เป็นของผู้ทำแต่ละเกม ควรตรวจกฎของเกมที่คุณเล่น

ส่งอะไรออกอินเทอร์เน็ตบ้าง?

การตรวจอัปเดตติดต่อ github.com โดยไม่ส่งข้อมูลของคุณ การหาไดรเวอร์ใช้ Windows Update การทดสอบเครือข่ายส่ง ping ไปยัง DNS สาธารณะเมื่อคุณสั่งเริ่ม ชุดไฟล์สนับสนุนแทนที่ข้อมูลส่วนตัวและไม่เคยถูกส่งออกไป

ใช้กับโน้ตบุ๊กได้ไหม?

ออกแบบสำหรับเดสก์ท็อป ในโน้ตบุ๊ก Easy Setup จะข้ามค่าที่ทำให้ร้อนและกินแบตเตอรี่

รันซ้ำสองรอบได้ไหม?

ได้ ปลอดภัย จะได้จุดกู้คืนใหม่ชื่อเดิม และ 2_Revert_Everything ย้อนไปจุดล่าสุด

ถอนการติดตั้งอย่างไร?

ไม่มีตัวติดตั้ง ย้อนค่าด้วย 2_Revert_Everything หรือเมนู 7 แล้วลบโฟลเดอร์ทิ้ง

รายงานอยู่ที่ไหน?

ในโฟลเดอร์ Logs ข้างโปรแกรม เก็บล่าสุดสามไฟล์ของแต่ละชนิด

มีค่าใช้จ่ายไหม?

ไม่มี ฟรีและเป็นโอเพนซอร์ส (ลิขสิทธิ์ MIT)

77_Driver_Check (เบต้า, เมนู D)
  • สแกนหาอุปกรณ์ที่ไม่มีไดรเวอร์ที่ใช้งานได้ แสดงการ์ดจอและอายุไดรเวอร์ และแสดงไดรเวอร์ที่ Windows Update มีให้ ทำมาสำหรับตอนเพิ่งลง Windows ใหม่เป็นหลัก แต่ใช้ได้ทุกเวลา
  • ถามก่อนเสมอ: A = ติดตั้งตัวที่แนะนำ, E = ทุกอย่างในรายการ, S = เลือกทีละตัว, G = เปิดหน้าไดรเวอร์การ์ดจออย่างเป็นทางการ, C = ล้างไดรเวอร์เวอร์ชันเก่า, N = ไม่ทำอะไร (ค่าเริ่มต้น)
  • การติดตั้งใช้ Windows Update จึงเป็นไดรเวอร์ที่ Microsoft เซ็นรับรอง ก่อนติดตั้งครั้งแรกจะสร้างจุดคืนค่าและเก็บสำเนาไดรเวอร์ปัจจุบันไว้ที่ Backup\drivers_เวลา ติดตั้งทีละตัว ไม่รีสตาร์ทเครื่องเอง และบอกวิธีย้อนกลับ: Roll Back Driver ใน Device Manager, System Restore หรือสำเนาที่เก็บไว้
  • เครื่องมือนี้ไม่ติดตั้งให้: ไดรเวอร์การ์ดจอจากผู้ผลิต, BIOS และ firmware สำหรับการ์ดจอจะเปิดหน้าอย่างเป็นทางการของ NVIDIA, AMD หรือ Intel ส่วนชุด chipset เต็ม, BIOS และ Wi-Fi/LAN จะบอกชื่อเมนบอร์ดหรือโน้ตบุ๊กของคุณเพื่อไปหาหน้าซัพพอร์ต ไดรเวอร์การ์ดจอจาก Windows Update จะถูกข้ามถ้าคุณมีไดรเวอร์จากผู้ผลิตอยู่แล้ว เพราะอาจเก่ากว่า แพ็กเกจ chipset INF ขนาดเล็กที่ Windows Update เสนอ (ชื่อแบบ "Intel chipset driver package 10.1.1.38") จะแสดงเป็นข้อเสริม
  • รายการที่ผลน้อย (เช่นอุปกรณ์ย่อยของ CPU และจอภาพ) แสดงเป็นข้อเสริม จัดกลุ่มตามผู้ผลิต และไม่รวมอยู่ใน "แนะนำ"
  • ถ้าเพิ่งลง Windows และยังไม่มีไดรเวอร์เครือข่าย จะเข้า Windows Update ไม่ได้ ให้ติดตั้งไดรเวอร์ LAN หรือ Wi-Fi จากผู้ผลิตเมนบอร์ดหรือโน้ตบุ๊กก่อน (ใช้อีกเครื่องกับแฟลชไดรฟ์)
  • หลังติดตั้งจะถาม Windows Update ซ้ำและบอกว่าเหลืออะไร รายการที่ขึ้นว่าล้มเหลวเพราะมีแพ็กเกจก่อนหน้าครอบคลุมอุปกรณ์นั้นแล้ว จะนับเป็น "ไม่จำเป็น" ไม่ใช่ข้อผิดพลาด
  • C = ล้างไดรเวอร์ (เบต้า) แสดง (A) ไดรเวอร์เวอร์ชันเก่าของอุปกรณ์ที่คุณยังใช้ ซึ่ง Windows เก็บไว้ใน driver store (เช่น NVIDIA รุ่นเก่า มักตัวละหลายร้อย MB) และ (B) รายการอุปกรณ์ที่ไม่ได้เชื่อมต่ออยู่แล้ว (USB เก่า จอภาพ) เวอร์ชันใหม่สุด เวอร์ชันที่กำลังใช้ และแพ็กเกจที่จำเป็นต่อการบูต จะถูกเก็บไว้เสมอ ก่อนลบจะสร้างจุดคืนค่า Before_Driver_Cleanup และเก็บสำเนาแต่ละแพ็กเกจไว้ที่ Backup\drivers_removed_เวลา ถ้าเก็บสำเนาไม่ได้ จะไม่ลบแพ็กเกจนั้น ไม่มีการบังคับลบ ถ้า Windows บอกว่ายังจำเป็นอยู่ก็จะคงไว้ รายการเครือข่าย ดิสก์ และระบบจะแสดงแต่ไม่ลบ รายการ Bluetooth จะถูกเก็บไว้เพราะอุปกรณ์อาจแค่ปิดอยู่ แพ็กเกจของ Microsoft และกลุ่มที่เลขเวอร์ชันสูงสุดไม่ใช่ตัวที่วันที่ใหม่สุด (ผู้ผลิตเปลี่ยนวิธีตั้งเลข) จะไม่ถูกแตะ และระบุชื่อไว้ในรายการ ไดรเวอร์ของฮาร์ดแวร์ที่แค่ถอดไว้ชั่วคราวจะไม่ถูกแตะโดยตั้งใจ
  • ความคาดหวังที่เป็นจริงของ C: ได้พื้นที่ดิสก์คืนและ Device Manager เป็นระเบียบ ไม่ทำให้ FPS สูงขึ้นหรือปิงต่ำลง
  • เบต้า: การติดตั้งไดรเวอร์ยังไม่ได้ทดสอบกับเครื่องจำนวนมาก อ่านรายการก่อนตอบ และเก็บจุดคืนค่าไว้

  • มีหมายเหตุสั้นๆ ใต้บางส่วนว่าตัวเลขนั้นหมายถึงอะไร (เช่นแรมเท่าไรถึงพอ) เป็นแนวทางทั่วไป ไม่ใช่คำตัดสิน
