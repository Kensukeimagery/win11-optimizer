คู่มือการใช้งาน v4.8

Windows 11 Optimizer

รวมทุกอย่างไว้ในเมนูเดียว พร้อมระบบสำรองและย้อนกลับรายข้อ

อ่านก่อนใช้

  • ใช้ด้วยความเสี่ยงของตัวเอง สคริปต์แก้ registry และ power settings ใช้กับเครื่องที่เป็นของคุณเท่านั้น และเก็บจุดคืนค่าที่สคริปต์สร้างไว้เสมอ
  • ออกแบบสำหรับ เดสก์ท็อป Windows 11 ที่เล่นเกม ถ้าใช้กับโน้ตบุ๊ก ความร้อนจะสูงขึ้นและแบตเตอรี่หมดเร็วขึ้น (CPU ขั้นต่ำ 100%, ปิด power throttling)
  • ผลที่ได้เล็กน้อยและขึ้นกับสถานการณ์ ไดรเวอร์การ์ดจอ การตั้งค่าในเกม XMP/EXPO และการระบายความร้อนสำคัญกว่ามาก ดูหมายเหตุตามจริงของแต่ละข้อด้านล่าง
  • แอนตี้ไวรัสบางตัวอาจเตือนไฟล์ .bat ที่แก้ registry ทุกไฟล์เป็นข้อความธรรมดา เปิดอ่านก่อนรันได้

สิ่งที่ต้องมี

  • Windows 11 (build 22000 ขึ้นไป) และบัญชีผู้ดูแลระบบ (คลิกขวา > Run as administrator) ถ้าเป็น Windows รุ่นเก่า เมนูจะเตือนก่อน ถ้าตรวจพบว่าเป็นโน้ตบุ๊ก จะแนะนำไม่ให้ใช้ข้อ 02 และ 16 และถามก่อนใช้ข้อ 02
  • เก็บทุกโฟลเดอร์ไว้ข้างสคริปต์ อย่าแยกไฟล์ .bat ออกจากโฟลเดอร์
  • เปิด System Protection (System Restore) ของไดรฟ์ระบบไว้ เพื่อให้สร้างจุดคืนค่าได้

เริ่มใช้งานแบบเร็ว

3 ขั้นตอนจบ

1เปิด 1_Start_Here - PC_Optimizer_Master
  • คลิกขวา แล้วเลือก Run as administrator
2พิมพ์ 5 แล้วกด Enter
  • สคริปต์สร้างจุดคืนค่าให้ก่อน แล้วทำเมนู 1, 2, 3, 4 ต่อกันอัตโนมัติ
  • เมนู 2 จะถามทีละข้อ ตอบตามการใช้งานของคุณ (ดูคำแนะนำของไฟล์ 09-13)
  • ขั้นสร้างจุดคืนค่าปกติใช้ 1-5 นาที ถ้าเกิน 10 นาทีสคริปต์จะหยุดรอแล้วถามว่าจะทำต่อไหม
3รีสตาร์ทเครื่อง 1 ครั้ง
  • จำเป็นสำหรับ GPU Scheduling, Memory Integrity และค่าระดับระบบอื่นๆ
  • จากนั้นทำรายการ "ตั้งค่า Windows เพิ่มเติม" ในคู่มือนี้ต่อ
  • หลังอัปเดต Windows ครั้งใหญ่ หรือทุก 1-2 เดือน ให้รัน 3_Check_Status

ถ้ามีปัญหา: ย้อนกลับได้ 3 ระดับ

เลือกระดับเล็กที่สุดที่แก้ปัญหาได้

Aย้อนทีละข้อ - เมนู 7
  • เช่น เมาส์รู้สึกแปลกหลังใช้ไฟล์ 10 ให้พิมพ์ 7 แล้ว 10
  • คืนเป็นค่าเริ่มต้นของ Windows จากโฟลเดอร์ reg_undo T = เอาค่า network ออก, P = รีเซ็ต Power Plan ทั้งหมด
  • สคริปต์จำไว้ว่าคุณย้อนข้อนี้ ตัวตรวจสถานะจะแสดงเป็น SKIPPED และไม่ถามให้ลงซ้ำ
Bคืนค่าเดิมแบบตรงตัว - โฟลเดอร์ Backup
  • ทุกครั้งที่รัน สคริปต์ export คีย์เดิมไว้ใน Backup\วันเวลา
  • ดับเบิลคลิกไฟล์ในนั้นเพื่อคืนค่าที่เครื่องคุณเคยมีจริง (ละเอียดกว่าค่าเริ่มต้นของ Windows)
Cย้อนทั้งเครื่อง - 2_Revert_Everything
  • ใช้ System Restore กลับไปจุด Before_PC_Optimizer
  • เครื่องรีสตาร์ทเอง และโปรแกรมที่ติดตั้งหลังจุดนั้นจะหายด้วย ใช้เมื่อปัญหาหนักเท่านั้น

ตรวจสอบสถานะ

3_Check_Status หรือเมนู C ใช้หลังอัปเดต Windows หรือทุก 1-2 เดือน

1รัน 3_Check_Status แบบ administrator
  • สคริปต์ไล่ตรวจทุกรายการ แสดงสถานะทีละบรรทัดพร้อมค่าปัจจุบันเทียบกับค่าที่ควรเป็น
2ตอบคำถามแก้ไข
  • ข้อแนะนำ: Y = ลงซ้ำทุกข้อที่หาย, S = เลือกทีละข้อ, N = ไม่แก้
  • ข้อเสริมถามทีละข้อเสมอ ส่วนข้อ 13 ต้องพิมพ์ YES
  • ก่อนลงซ้ำจะสำรองค่าเดิมไว้ใน Backup\วันเวลา_check
3ตรวจซ้ำอัตโนมัติ
  • หลังแก้เสร็จสคริปต์ตรวจข้อที่แก้อีกรอบเพื่อยืนยัน บันทึกผลเป็น CheckReport_วันเวลา.txt แล้วรีสตาร์ท 1 ครั้ง
สถานะหมายความว่าสิ่งที่สคริปต์ทำ
OKค่ายังอยู่ครบตามที่สคริปต์ตั้งไว้ไม่ต้องทำอะไร
CHANGEDมีบางค่าถูกเปลี่ยน เช่นหลังอัปเดต Windowsลงซ้ำได้
MISSINGไม่พบค่าของข้อนี้เลยลงซ้ำได้
NOT CHOSENข้อเสริม (09-13) ที่ยังไม่เคยตอบถาม: Y ลง, N ยังไม่ลง, X ไม่ต้องถามอีก
SKIPPEDข้อที่คุณเลือกข้ามหรือย้อนกลับไว้ไม่ถาม ไม่แก้
UNKNOWNอ่านค่าไม่ได้ หรือเครื่องไม่มีตัวเลือกนี้ให้ข้อมูลเท่านั้น

สิ่งที่ตรวจ: ไฟล์ .reg ทั้ง 14 ไฟล์ (อ่านจากไฟล์ตัวเดียวกับที่ใช้ลง), Power Plan (Ultimate Performance หรือ High Performance ถ้าไม่มี Ultimate), ค่า power 4 ตัว, Prefetcher (SSD ต้องเป็น 0, HDD ต้องเป็น 3), TcpAckFrequency และ TCPNoDelay ของทุก adapter, services DiagTrack และ dmwappushservice และข้อเสริม 15, 16 และ 17 (เมื่อเคยใช้) (ข้อ 16: boost mode 2 และ preference 0 ตอนเสียบปลั๊ก)
ข้อจำกัด: ตัวตรวจบอกได้ว่าค่ายังอยู่ แต่ไม่ได้ว่ายังมีผลจริง (ข้อ 08 อาจขึ้น OK แม้การ์ดจอไม่รองรับ GPU Scheduling) ค่าใต้ GameConfigStore (01, 09) ถูก Windows และ Xbox Game Bar เขียนทับเองได้ ขึ้น CHANGED บ่อยจึงไม่แปลกว่ามีอะไรผิด และถ้าเพิ่งติดตั้ง VPN หรือการ์ด Wi-Fi ใหม่ หัวข้อ Network จะขึ้น CHANGED จนกว่าจะตั้งค่า adapter นั้น

Uการอัปเดต: เมนู U หรือ 6_Check_For_Updates.bat
  • ตรวจหาเวอร์ชันใหม่บน GitHub แสดงว่ามีอะไรใหม่ และติดตั้งเฉพาะเมื่อคุณกด U N = ยังไม่ทำ, S = ข้ามเวอร์ชันนี้, L = เปิดหน้า Release
  • ออกแบบให้ปลอดภัย: ไฟล์ที่ดาวน์โหลดถูกตรวจกับค่า SHA-256 ที่ประกาศพร้อม Release เวอร์ชันเดิมถูกย้ายไป Backup\update_เวอร์ชันเดิม_เวลา และถ้าขั้นตอนใดล้มเหลวจะใส่กลับให้ โฟลเดอร์ Backup, log และรายงานของคุณไม่ถูกแตะเลย
  • ครั้งแรกที่เปิดเมนูจะถามหนึ่งครั้งว่าจะตรวจอัตโนมัติตอนเริ่มไหม (เชื่อมต่อ github.com และไม่ส่งข้อมูลเกี่ยวกับคุณ) กด A เพื่อเปิดหรือปิด ไม่มีอะไรถูกติดตั้งโดยที่คุณไม่เลือก
  • การอัปเดตจาก v4.5 หรือเก่ากว่าต้องดาวน์โหลด ZIP เองหนึ่งครั้ง ตั้งแต่ v4.6 เป็นต้นไป โปรแกรมอัปเดตตัวเองได้

ไฟล์ .reg หมวด 1: Recommended (01-08)

รันผ่านเมนู 1 ออกแบบให้ปลอดภัยสำหรับเครื่องส่วนใหญ่

01GameBar_DVR_Off
  • ปิดการอัดคลิปเบื้องหลังของ Xbox Game Bar (Game DVR) ทั้งระดับผู้ใช้และ Policy เปิด Game Mode ไว้ (v3 ปิดไปโดยไม่ตั้งใจ)
ช่วยอะไร: คืน CPU/GPU/ดิสก์ที่ใช้อัดหน้าจอตลอดเวลา ค่าเหล่านี้ไม่มีเอกสารทางการของ Microsoft
02Power_Throttling_Off
  • PowerThrottlingOff = 1 ไม่ลดความเร็วโปรแกรมเบื้องหลัง ปิด Energy Estimation และปิด Fast Startup ให้การ Shutdown เป็นการเริ่มระบบใหม่จริง
ช่วยอะไร: Discord/OBS เบื้องหลังไม่โดนลดสปีด ข้อเสีย: บูตช้าลงเล็กน้อย และกินไฟมากขึ้นในโน้ตบุ๊ก
03Gaming_Priority_MMCSS
  • NetworkThrottlingIndex = ffffffff ยกเลิกการจำกัดเน็ตของงานมัลติมีเดีย
  • SystemResponsiveness = 10 ซึ่งเป็นค่าต่ำสุดที่มีผลจริง Microsoft ระบุว่าค่าต่ำกว่า 10 จะถูกปัดกลับเป็น 20 (ค่าเริ่มต้น) ค่า 0 จึงไม่มีผลเลย
  • Tasks\Games: GPU Priority 8, Priority 6, Scheduling Category High, SFIO Priority High
ช่วยอะไร: จัดคิวงานให้เกมได้ CPU, GPU และดิสก์ก่อนโปรแกรมอื่น
04CPU_Foreground_Priority
  • Win32PrioritySeparation = 0x26 ให้หน้าต่างที่ใช้งานอยู่ได้ช่วงเวลา CPU ยาวและสำคัญกว่า (ค่าเริ่มต้นคือ 0x2)
ช่วยอะไร: เกมที่เปิดอยู่ตรงหน้าได้ CPU มากกว่าโปรแกรมเบื้องหลัง
05Telemetry_Off
  • AllowTelemetry = 0, CEIPEnable = 0 บน Windows Home/Pro จะใช้ระดับต่ำสุดที่อนุญาตแทน ค่า 0 เต็มรูปแบบมีผลเฉพาะ Enterprise
ช่วยอะไร: ลดการส่งข้อมูลเบื้องหลัง ผลต่อ FPS เล็กน้อย เน้นความเป็นส่วนตัว
06System_Responsiveness
  • เมนูขึ้นทันที ปิดโปรแกรมค้างเร็วขึ้น ลด animation และ Visual Effects
  • ปิดการบันทึกเวลาเข้าถึงไฟล์ NTFS คืนเมนูคลิกขวา Copy To / Move To
ช่วยอะไร: Windows ตอบสนองไวขึ้น ลดการเขียนดิสก์ที่ไม่จำเป็น
07Delivery_Optimization_Off
  • DODownloadMode = 0
ช่วยอะไร: Windows Update ไม่แอบอัปโหลดไฟล์ให้เครื่องอื่นระหว่างเล่นเกมออนไลน์
08GPU_Scheduling_On
  • HwSchMode = 2 เปิด Hardware-accelerated GPU Scheduling ต้องรีสตาร์ท และต้องใช้การ์ดจอ/ไดรเวอร์ที่รองรับ ถ้าไม่รองรับ Windows ไม่สนใจค่านี้
ช่วยอะไร: ลด latency ระหว่าง CPU กับ GPU เล็กน้อย Microsoft ระบุว่าผู้ใช้ส่วนใหญ่ไม่ควรคาดหวังการเปลี่ยนแปลงมาก

44_Network_Test.bat
  • ส่ง ping ตัวละ 30 ครั้งไปที่เราเตอร์ 1.1.1.1 8.8.8.8 และเซิร์ฟเวอร์เกมถ้าคุณพิมพ์ใส่ (เป็นแพ็กเก็ต ping ธรรมดา) แสดง ping เฉลี่ย jitter และ packet loss ให้เกรด Good / Fair / Poor แต่ละบรรทัด และบอกว่าปัญหาน่าจะอยู่ตรงไหน
  • Jitter คือความแกว่งของค่าหน่วง ซึ่งเป็นสิ่งที่รู้สึกเป็นอาการกระชาก (rubber-banding) และสำคัญกว่า ping เฉลี่ยที่สูงขึ้นนิดหน่อย
  • ผลบันทึกเป็น NetworkTest_วันเวลา.txt ข้างสคริปต์
  • ความเร็ว DNS: จากนั้นวัดเวลาการค้นหาจริง 8 เว็บยอดนิยมบน DNS ปัจจุบันของคุณ และ Cloudflare (1.1.1.1), Google (8.8.8.8), Quad9 (9.9.9.9) แล้วบอกว่าตัวที่เร็วสุดเร็วกว่าเท่าไร ต่อด้วยถามว่าจะเปลี่ยน DNS ไหม คุณเลือกเลขเอง หรือกด Enter เพื่อไม่เปลี่ยนอะไร
17DNS servers (ข้อเสริม คุณเลือกเอง)
  • ตั้ง DNS IPv4 ของการ์ดเน็ต Ethernet และ Wi-Fi ที่ใช้งานอยู่เป็นผู้ให้บริการที่คุณเลือก การ์ด VPN และการ์ดเสมือนไม่ถูกแตะ Windows จะขอสิทธิ์ผู้ดูแลระบบตอนคุณยืนยัน
  • สคริปต์เก็บค่า DNS เดิมไว้ก่อน (รวมถึงแบบ "obtain automatically") ย้อนกลับ: รันเทสต์อีกครั้งแล้วเลือก U หรือใช้เมนู 7 แล้ว 17
  • Check Status แสดงข้อนี้หลังคุณเคยใช้ และตั้งซ้ำให้ถ้า Windows update หรือ VPN เปลี่ยนค่าไป
มีผลมากแค่ไหน? DNS ใช้ครั้งเดียวตอนต่อเข้าเว็บหรือเซิร์ฟเวอร์เกม ไม่ได้เปลี่ยน ping หรือ FPS ในเกม DNS ที่เร็วกว่าอาจทำให้เปิดเว็บและ launcher เร็วขึ้นเล็กน้อย และ DNS ที่เสียอาจทำให้เว็บโหลดไม่ขึ้น ถ้า DNS ปัจจุบันของคุณช้ากว่าตัวที่ดีที่สุดไม่ถึง 5 ms ไม่ต้องเปลี่ยน ผู้ให้บริการ DNS ที่เลือกจะเห็นชื่อเว็บที่คุณเข้า
สิ่งที่เห็นสาเหตุที่เป็นไปได้มากสุดลองทำ
บรรทัด Router เป็น Fair หรือ Poorสัญญาณ Wi-Fi สายเสีย หรืออุปกรณ์อื่นใช้เน็ตอยู่ใช้สาย LAN เข้าใกล้เราเตอร์ หยุดดาวน์โหลดและสตรีมในเครื่องอื่น
Router ดี แต่บรรทัด Internet เป็น Poorผู้ให้บริการอินเทอร์เน็ตหรือสายสัญญาณรีสตาร์ทเราเตอร์ ถ้ายังเป็นให้ติดต่อผู้ให้บริการ
Router และ Internet ดี แต่เซิร์ฟเวอร์เกมแย่อย่างเดียวเส้นทางไปเซิร์ฟเวอร์นั้น หรือตัวเซิร์ฟเวอร์เองเลือกเซิร์ฟเวอร์หรือภูมิภาคอื่น ไม่มีอะไรในเครื่องคุณแก้ได้

77_Driver_Check (เบต้า, เมนู D)
  • สแกนหาอุปกรณ์ที่ไม่มีไดรเวอร์ที่ใช้งานได้ แสดงการ์ดจอและอายุไดรเวอร์ และแสดงไดรเวอร์ที่ Windows Update มีให้ ทำมาสำหรับตอนเพิ่งลง Windows ใหม่เป็นหลัก แต่ใช้ได้ทุกเวลา
  • ถามก่อนเสมอ: A = ติดตั้งตัวที่แนะนำ, E = ทุกอย่างในรายการ, S = เลือกทีละตัว, G = เปิดหน้าไดรเวอร์การ์ดจออย่างเป็นทางการ, C = ล้างไดรเวอร์เวอร์ชันเก่า, N = ไม่ทำอะไร (ค่าเริ่มต้น)
  • การติดตั้งใช้ Windows Update จึงเป็นไดรเวอร์ที่ Microsoft เซ็นรับรอง ก่อนติดตั้งครั้งแรกจะสร้างจุดคืนค่าและเก็บสำเนาไดรเวอร์ปัจจุบันไว้ที่ Backup\drivers_เวลา ติดตั้งทีละตัว ไม่รีสตาร์ทเครื่องเอง และบอกวิธีย้อนกลับ: Roll Back Driver ใน Device Manager, System Restore หรือสำเนาที่เก็บไว้
  • เครื่องมือนี้ไม่ติดตั้งให้: ไดรเวอร์การ์ดจอจากผู้ผลิต, BIOS และ firmware สำหรับการ์ดจอจะเปิดหน้าอย่างเป็นทางการของ NVIDIA, AMD หรือ Intel ส่วนชุด chipset เต็ม, BIOS และ Wi-Fi/LAN จะบอกชื่อเมนบอร์ดหรือโน้ตบุ๊กของคุณเพื่อไปหาหน้าซัพพอร์ต ไดรเวอร์การ์ดจอจาก Windows Update จะถูกข้ามถ้าคุณมีไดรเวอร์จากผู้ผลิตอยู่แล้ว เพราะอาจเก่ากว่า แพ็กเกจ chipset INF ขนาดเล็กที่ Windows Update เสนอ (ชื่อแบบ "Intel chipset driver package 10.1.1.38") จะแสดงเป็นข้อเสริม
  • รายการที่ผลน้อย (เช่นอุปกรณ์ย่อยของ CPU และจอภาพ) แสดงเป็นข้อเสริม จัดกลุ่มตามผู้ผลิต และไม่รวมอยู่ใน "แนะนำ"
  • ถ้าเพิ่งลง Windows และยังไม่มีไดรเวอร์เครือข่าย จะเข้า Windows Update ไม่ได้ ให้ติดตั้งไดรเวอร์ LAN หรือ Wi-Fi จากผู้ผลิตเมนบอร์ดหรือโน้ตบุ๊กก่อน (ใช้อีกเครื่องกับแฟลชไดรฟ์)
  • หลังติดตั้งจะถาม Windows Update ซ้ำและบอกว่าเหลืออะไร รายการที่ขึ้นว่าล้มเหลวเพราะมีแพ็กเกจก่อนหน้าครอบคลุมอุปกรณ์นั้นแล้ว จะนับเป็น "ไม่จำเป็น" ไม่ใช่ข้อผิดพลาด
  • C = ล้างไดรเวอร์ (เบต้า) แสดง (A) ไดรเวอร์เวอร์ชันเก่าของอุปกรณ์ที่คุณยังใช้ ซึ่ง Windows เก็บไว้ใน driver store (เช่น NVIDIA รุ่นเก่า มักตัวละหลายร้อย MB) และ (B) รายการอุปกรณ์ที่ไม่ได้เชื่อมต่ออยู่แล้ว (USB เก่า จอภาพ) เวอร์ชันใหม่สุด เวอร์ชันที่กำลังใช้ และแพ็กเกจที่จำเป็นต่อการบูต จะถูกเก็บไว้เสมอ ก่อนลบจะสร้างจุดคืนค่า Before_Driver_Cleanup และเก็บสำเนาแต่ละแพ็กเกจไว้ที่ Backup\drivers_removed_เวลา ถ้าเก็บสำเนาไม่ได้ จะไม่ลบแพ็กเกจนั้น ไม่มีการบังคับลบ ถ้า Windows บอกว่ายังจำเป็นอยู่ก็จะคงไว้ รายการเครือข่าย ดิสก์ และระบบจะแสดงแต่ไม่ลบ ไดรเวอร์ของฮาร์ดแวร์ที่แค่ถอดไว้ชั่วคราวจะไม่ถูกแตะโดยตั้งใจ
  • ความคาดหวังที่เป็นจริงของ C: ได้พื้นที่ดิสก์คืนและ Device Manager เป็นระเบียบ ไม่ทำให้ FPS สูงขึ้นหรือปิงต่ำลง
  • เบต้า: การติดตั้งไดรเวอร์ยังไม่ได้ทดสอบกับเครื่องจำนวนมาก อ่านรายการก่อนตอบ และเก็บจุดคืนค่าไว้

สิ่งที่ช่วยให้ FPS นิ่งและ ping ต่ำจริงๆ

  • จำกัด FPS ให้ต่ำกว่า refresh rate ของจอ 3-4 เฟรม (ในเกม, RTSS หรือ NVIDIA Control Panel) ได้ frame time นิ่งกว่าเกมที่ไม่จำกัดจนการ์ดจอเต็ม
  • เปิด NVIDIA Reflex (หรือ Low Latency Mode) ถ้าเกมมีให้
  • ใช้สาย LAN Jitter ของ Wi-Fi เป็นสาเหตุ ping แย่ที่พบบ่อยที่สุด
  • อัปเดตไดรเวอร์การ์ดจอ ระบายความร้อนให้ดี และปิดโปรแกรมหนักก่อนเล่น
  • registry tweak ในโปรเจกต์นี้ไม่มีตัวไหนลด ping ได้ชัดเจน และการเปลี่ยน DNS ก็ไม่ลด ทั้งหมดเป็นผลเล็กเฉพาะสถานการณ์
