User Manual v4.4

Windows 11 Optimizer

One menu for every tweak, with backups and one-by-one revert

Read this first

  • Use at your own risk. These scripts edit the Windows registry and power settings. Use them only on a PC you own. Always keep the restore point the script creates.
  • Built for Windows 11 desktops used for gaming. On a laptop expect more heat and faster battery drain (processor minimum 100%, power throttling off).
  • The gains are small and situational. GPU drivers, in-game settings, XMP/EXPO and cooling matter far more. See the honest notes on each tweak below.
  • Some antivirus programs flag .bat files that edit the registry. Every file is plain text: open and read it before you run it.

Requirements

  • Windows 11 and an administrator account (right-click > Run as administrator).
  • Keep every folder next to the scripts. Do not move a .bat file out of the folder.
  • System Protection (System Restore) turned on for the system drive, so the restore point can be created.

Quick start

Three steps

1Open 1_Start_Here - PC_Optimizer_Master
  • Right-click > Run as administrator.
2Type 5 and press Enter
  • The script creates a restore point, then runs menus 1, 2, 3 and 4 in order.
  • Menu 2 asks about each optional tweak. Answer for your own use (see the notes on files 09-13).
  • A restore point normally takes 1-5 minutes. After 10 minutes the script stops waiting and asks whether to continue.
3Restart once
  • Needed for GPU scheduling, Memory Integrity and other system-level values.
  • Then work through the manual Windows settings later in this guide.
  • After a big Windows update, or every 1-2 months, run 3_Check_Status.

If something goes wrong

Three levels of undo: pick the smallest one that fixes it

ARevert one tweak: menu 7
  • Example: the mouse feels odd after file 10. Type 7, then 10.
  • Restores the Windows default from reg_undo. T removes the network values, P resets all power plans.
  • The script remembers the revert; the status check shows it as SKIPPED and will not offer to apply it again.
BRestore your exact previous values: Backup folder
  • Every run exports the old keys to Backup\date-time.
  • Double-click a file there to restore the value your PC really had (more precise than the Windows default).
CRoll back the whole PC: 2_Revert_Everything
  • Uses System Restore to return to the Before_PC_Optimizer restore point.
  • The PC restarts by itself, and programs installed after that point are removed. Serious problems only.

Status check

3_Check_Status, or menu C. Use it after a Windows update or every 1-2 months

1Run 3_Check_Status as administrator
  • It checks every item and prints each line with the current value against the expected one.
2Answer the fix questions
  • Recommended items: Y = re-apply everything missing, S = choose one by one, N = change nothing.
  • Optional items are always asked one by one; file 13 still needs YES.
  • The old values are backed up to Backup\date-time_check before anything is re-applied.
3Automatic re-check
  • After fixing, the script checks the fixed items again to confirm. Everything is saved to CheckReport_date-time.txt. Restart once.
StatusMeaningWhat the script does
OKThe value is still as the script set it.Nothing.
CHANGEDA value was changed, for example by a Windows update.Can re-apply it.
MISSINGThe value is not there at all.Can re-apply it.
NOT CHOSENAn optional tweak (09-13) you never answered.Asks: Y apply, N not now, X never ask again.

What it checks: all 14 .reg files (read from the same files that are applied), the power plan (Ultimate Performance, or High Performance if Ultimate is unavailable), the four power values, Prefetcher (SSD must be 0, HDD must be 3), TcpAckFrequency and TCPNoDelay on every adapter, and the DiagTrack / dmwappushservice services. Optional 15 and 16 are checked too (16: boost mode 2 and preference 0 while plugged in).
Limits: it tells you a value is still there, not that it still has an effect (item 08 can show OK on a GPU that does not support GPU scheduling). Values under GameConfigStore (01, 09) are rewritten by Windows and the Xbox Game Bar, so CHANGED there is common. Adding a new VPN or Wi-Fi adapter makes Network show CHANGED until it is configured.

.reg files, group 1: Recommended (01-08)

Menu 1. Meant to be safe for most PCs

01GameBar_DVR_Off
  • Turns off Xbox Game Bar background recording (Game DVR), at user and policy level. Game Mode is kept on (v3 turned it off by mistake).
Helps: gives back CPU, GPU and disk time used for constant recording. No official Microsoft documentation for these values.
02Power_Throttling_Off
  • PowerThrottlingOff = 1 stops Windows slowing background programs. Energy estimation off. Fast Startup off, so Shutdown is a real clean restart.
Helps: Discord or OBS in the background are not slowed down. Cost: slightly longer boot, and more power use on laptops.
03Gaming_Priority_MMCSS
  • NetworkThrottlingIndex = ffffffff removes the network limit for multimedia tasks.
  • SystemResponsiveness = 10, the lowest value that takes effect. Microsoft documents that values below 10 are raised to the default of 20, so a value of 0 does nothing.
  • Tasks\Games: GPU Priority 8, Priority 6, Scheduling Category High, SFIO Priority High.
Helps: queues work so the game gets CPU, GPU and disk first.
04CPU_Foreground_Priority
  • Win32PrioritySeparation = 0x26: the active window gets longer, higher-priority CPU time slices (default is 0x2).
Helps: the game in front gets more CPU than background programs.
05Telemetry_Off
  • AllowTelemetry = 0, CEIPEnable = 0. On Home and Pro, Windows uses the lowest level it allows; true 0 only applies to Enterprise.
Helps: less background data sent. Tiny effect on FPS; mostly privacy.
06System_Responsiveness
  • Menus appear instantly, frozen apps are closed faster, lighter animations and visual effects.
  • NTFS last-access time stamps off; the classic Copy To / Move To right-click entries restored.
Helps: Windows feels quicker, fewer needless disk writes.
07Delivery_Optimization_Off
  • DODownloadMode = 0.
Helps: Windows Update does not upload updates to other PCs while you play online.
08GPU_Scheduling_On
  • HwSchMode = 2 turns on hardware-accelerated GPU scheduling. Needs a restart and a supported GPU and driver; unsupported systems ignore it.
Helps: slightly lower CPU-to-GPU latency. Microsoft says most users should not expect a big change.

Optional tweaks (09-13, 15, 16)

The script asks about each one. Answer for how you actually play

09Fullscreen_Exclusive
  • Forces true Fullscreen Exclusive instead of letting Windows convert games to borderless.
  • Answer Y only if fullscreen games stutter or hang on alt-tab. Some newer games work better the default way.
Helps: lower input lag in older games that support Fullscreen Exclusive.
10Mouse_No_Acceleration
  • Turns off Enhance Pointer Precision so the mouse moves 1:1.
Helps: consistent aim in shooters.
11Keyboard_Fast_Repeat
  • KeyboardDelay = 0 (shortest delay before repeat). Flags = 122 stops the Filter Keys pop-up when Shift is held for 8 seconds in a game.
Helps: faster key response and no interrupting pop-up.
12Ndu_Memory_Fix
  • Disables the Ndu service (a memory leak reported on some PCs) and sets DisablePagingExecutive = 1.
  • Side effects: Task Manager stops showing per-app network history. Keeping the kernel in RAM costs memory, so skip it on PCs with 8 GB or less.
Helps: only if your RAM use keeps creeping up. The Ndu leak comes from user reports, not Microsoft documentation.
13Memory_Integrity_Off
  • Turns off Memory Integrity (HVCI). You must type YES, and restart.
  • Microsoft confirms it can affect gaming performance on some PCs (no figure given). With it off, Windows protects less against kernel-level malware.
  • Skip it on a work PC or one holding important data. Undo with menu 7, then 13.
Helps: the only tweak here that can raise FPS noticeably, at a security cost.
15Timer_Resolution
  • Sets GlobalTimerResolutionRequests = 1. Since Windows 10 2004 and Windows 11, a game's timer-resolution request only applies to that game. This value lets such a request apply system-wide again.
  • Can steady frame pacing in some games. Microsoft notes that a higher timer resolution uses more power and can keep the CPU from saving power. Needs a restart. Undo: menu 7, then 15.
Helps: frame pacing in some games, effect varies. The value comes from the tweaking community; Microsoft does not document it.
16CPU_Boost_Aggressive (power setting, no .reg file)
  • Plugged in only: processor performance boost mode = Aggressive (2) and energy performance preference = 0 (favour performance), on the active power plan.
  • Your earlier values are saved first, so menu 7, then 16 restores exactly those. The Ultimate Performance plan already uses these values on most PCs, so this mainly matters on High Performance or Balanced. Expect more heat, especially on laptops.
Helps: 1% lows in games limited by the CPU. Skipped automatically on PCs that do not offer these settings.

Group 3: Power (14) and automatic settings

Menu 4 does the whole job, no manual setup

14Unlock_CPU_Power_Settings
  • Makes visible the CPU options Windows hides: core parking, maximum frequency, boost mode, energy performance preference.
  • Merges files 11 and 12 of v3 and drops entries that are normally visible.
PWhat menu 4 then sets with powercfg
  • Minimum processor state = 100%. Core parking minimum = 100% (cores never sleep).
  • USB selective suspend = off. PCIe Link State Power Management = off.
  • Plugged-in values only; the battery profile on a laptop is not touched.
Helps: CPU and GPU do not switch to power-saving states mid-game.

Diagnostic tools

Read-only: they change nothing and need no administrator rights. Menu N and R run the same tools

44_Network_Test.bat
  • Sends 30 pings each to your router, 1.1.1.1, 8.8.8.8 and, if you type one, a game server (these are ordinary ping packets). It shows average ping, jitter and packet loss, grades each line Good / Fair / Poor and says where the problem most likely is.
  • Jitter is how much the delay jumps around. It is what you feel as rubber-banding, and it matters more than a slightly higher average ping.
  • The result is saved as NetworkTest_date-time.txt next to the scripts.
What you seeMost likely causeWhat to try
Router line is Fair or PoorWi-Fi signal, a bad cable, or other devices using the network.Use a cable, move closer, pause other downloads and streams.
Router is Good, internet lines are PoorYour internet provider or the line.Restart the router; if it stays, contact the provider.
Router and internet Good, only the game server is badThe route to that server, or the server itself.Choose another server or region. Nothing on your PC fixes this.
Game server shows "No reply"Many servers block ping.Not a problem by itself.
55_System_Report.bat
  • Lists Windows, CPU, RAM, graphics card and driver age, disks and free space, the power plan, the programs using the most CPU and RAM (browsers with many processes are added together), and the programs that start with Windows.
  • Ends with plain hints: long uptime, RAM nearly full, an old GPU driver, a drive with less than 15% free, a failing disk, too many startup programs.
  • Saved as SystemReport_date-time.txt. Your Windows user name is hidden in the file, but check it before you share it. Program names and paths are still listed.

What really helps steady FPS and low ping

  • Cap the frame rate 3-4 below your monitor's refresh rate (in the game, RTSS or the NVIDIA Control Panel). It gives steadier frame times than an uncapped game that pins the GPU.
  • Turn on NVIDIA Reflex (or Low Latency Mode) if your game offers it.
  • Use a network cable. Wi-Fi jitter is the most common cause of bad ping.
  • Keep GPU drivers current, keep the PC cool and close heavy programs before you play.
  • None of the registry tweaks in this project lowers ping by a noticeable amount. They are small, situational gains.

Folder: repair-tools

Targeted repair tools. Not needed on every run. Right-click > Run as administrator

ADeep_Clean_Junk_Files.bat
  • Runs Disk Cleanup for every category, plus temp files. Reports free space before and after, and warns if less than 15% is left.
Use when: disk space is low, or every 1-2 months.
BNetwork_Reset_Fix_Internet.bat
  • Resets Winsock, IPv4 and IPv6, renews the IP address, flushes DNS and ARP, then pings to test.
Use when: the connection drops, will not connect, or is oddly slow.
CBluetooth_Fix.bat
  • Re-enables the pairing service and restarts the Bluetooth Support Service.
Use when: a device will not pair or connect.
DSystem_File_Scan_Repair.bat
  • DISM first, then SFC, the order Microsoft recommends (15-40 minutes). ResetBase is an optional Y/N question because it cannot be undone.
Use when: programs crash, freeze often, or you suspect damaged system files.
